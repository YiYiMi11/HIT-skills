# 规范原件（模板）

哈工大下发的**空白**模板与管理办法原件，供核对版式、直接填写使用。skill 里的写作/排版规范就是从这里逐条抽出来的，两者冲突时以**学院当年下发的版本**为准。

## 清单

### 大一年度项目（基础学部）

| 文件 | 校区 | 阶段 | 说明 |
|---|---|---|---|
| `annual-project/本部-大一年度项目-立项报告.doc` | 哈尔滨 | 立项 | 2000 字以上，六部分；含成员表、指导教师/专家组意见栏、批准经费 |
| `annual-project/本部-大一年度项目-中期检查报告.doc` | 哈尔滨 | 中期检查 | 2000 字左右，五小节；含专家组三项勾选 |
| `annual-project/本部-大一年度项目-结题报告.doc` | 哈尔滨 | 结题 | 3000 字左右，六部分；含项目成果表 |
| `annual-project/深圳-大一年度项目-立项报告.docx` | 深圳 | 立项 | 封面用“学院”，无辅导员栏 |

> 大创的**中期检查报告**没有独立 Word 模板，在大创管理系统内填报。

## 怎么用

1. 复制对应模板到自己的工作目录，**不要直接改原件**。
2. 填入字段，保留模板原有的字号、表格、签名位。
3. 需要按规范调整时，对照 skill 里的说明：
   - 写作要求：`skills/hit-assignment-report/references/annual-project.md` / `dachuang.md`
   - 排版要求：`skills/hit-standard-word-type/references/annual-project-format.md` / `dachuang-format.md`

## 来源与免责

- 全部为学校下发的**空白**模板：已核查，不含姓名、学号、手机号等个人信息。
- 管理办法为本科生院行政文件（校本〔2024〕61 号），注明文号与印发日期，供学习参考。
- 模板可能随年度修订。**正式提交前以学院/本科生院当年通知与系统内附件为准**，本仓库版本仅作版式参考。
- 若学校要求停止分发，请联系仓库维护者删除。
