# 规范原件（模板）

哈工大下发的模板、管理办法与书写范例原件，供核对版式、直接填写使用。其中大一年度项目与大创是**空白**制式表格，研究生学位论文是**带批注的示范稿**（两者的用法见下）。skill 里的写作/排版规范就是从这里逐条抽出来的，两者冲突时以**学院当年下发的版本**为准。

## 清单

### 研究生学位论文（研究生院）

| 文件 | 门类 | 说明 |
|---|---|---|

来源（哈尔滨工业大学研究生院）：

| 范例 | 官方地址 | 发布 |
|---|---|---|
| 研究生学位论文书写范例（理工类） | <https://hitgs.hit.edu.cn/2021/0513/c17373a317228/page.htm> | 2021-05-13 |
| 研究生学位论文书写范例（人文社科类） | <https://hitgs.hit.edu.cn/2021/0508/c17373a317224/page.htm> | 2021-05-08 |

两份范例是**带批注的示范稿**（正文用“↑（宋体小1号字加粗）”这类标注指出每处该用什么格式），不是空白模板。**不建议直接拿它当模板填**——示例文字、示例图表、示例公式要全部替换，容易漏改；建议按 `skills/hit-standard-word-type/references/graduate-thesis-format.md` 重建版式，用它核对。

> 理工类那份用 Word 打开约 22 MB，主要为插图示例；系统自带的文本转换工具可能报“格式不正确”，需要时用 Python 解析 OLE 复合文档取文本。

## 怎么用

1. 复制对应模板到自己的工作目录，**不要直接改原件**。
2. 填入字段，保留模板原有的字号、表格、签名位。
3. 需要按规范调整时，对照 skill 里的说明：
   - 写作要求：`skills/hit-assignment-report/references/annual-project.md` / `dachuang.md` / `graduate-thesis.md`
   - 排版要求：`skills/hit-standard-word-type/references/annual-project-format.md` / `dachuang-format.md` / `graduate-thesis-format.md`

## 来源与免责

- 大一年度项目与大创为学校下发的**空白**模板：已核查，不含姓名、学号、手机号等个人信息。
- 研究生学位论文两范例由哈尔滨工业大学研究生院发布于 <https://hitgs.hit.edu.cn/>（理工类 2021-05-13、人文社科类 2021-05-08），原件照录未改动（MD5 与官网下载件一致）；正文取自公开学位论文片段，仅作格式示范，不要把示例内容当研究素材。
- 管理办法为本科生院行政文件（校本〔2024〕61 号），注明文号与印发日期，供学习参考。
- 模板可能随年度修订。**正式提交前以学院/本科生院/研究生院当年通知与系统内附件为准**，本仓库版本仅作版式参考。
- 若学校要求停止分发，请联系仓库维护者删除。
