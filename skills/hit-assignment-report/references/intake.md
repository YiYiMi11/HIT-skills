## 四、硬性约束（易踩坑）

- [ ] 字数**是否含**图表、公式、参考文献？（多数不含，但要确认）
- [ ] 是否要求**查重**？查重率上限？（知网 PMLC/维普/万方，比例不同）
- [ ] 是否要求**AIGC 检测**？
- [ ] 是否需要**封面**？老师是否发了统一模板？
- [ ] 是否需要**目录、摘要、关键词、致谢**？
- [ ] 图表是否要求**三线表**、图题在下表题在上？
- [ ] 参考文献是否有**数量下限**？（常见“不少于 10 篇”，且常要求含近 5 年文献）
- [ ] 是否要求**外文文献**？
- [ ] 提交格式：docx / pdf？文件命名规则？

## 七、风险预判

填完上面这些，先回答三个问题，写进 `00-intake.md` 末尾：

1. **这份作业最容易丢分的地方是哪？**（通常不是内容，而是规范性——格式、文献、字数）
2. **有没有必须靠真实数据才能成立的论点？**（有 → 先确认用户有没有数据，没有就调整论点）
3. **文献要撑起哪几个环节？**（综述段落 / 方法依据 / 结论对比 / 现状描述）
