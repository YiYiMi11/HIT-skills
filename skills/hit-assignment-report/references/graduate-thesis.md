# 研究生学位论文（硕士 / 博士）

哈工大研究生院学位论文的写作规范。依据研究生院发布的两份书写范例：

- 《研究生学位论文书写范例（理工类）》<https://hitgs.hit.edu.cn/2021/0513/c17373a317228/page.htm>
- 《研究生学位论文书写范例（人文社科类）》<https://hitgs.hit.edu.cn/2021/0508/c17373a317224/page.htm>

排版细则见 [`../../hit-standard-word-type/references/graduate-thesis-format.md`](../../hit-standard-word-type/references/graduate-thesis-format.md)。

## 0. 覆盖范围（先说清边界）

**已覆盖**：学位论文本体——封面、内封、摘要、目录、正文各章、结论、参考文献、成果、声明、致谢、简历。

**未覆盖**：开题报告、中期检查、预答辩材料。这三类走学院/研究生院各自下发的表格，范例里没有。用户要这三类时，**如实说“规范未内置”，请对方给学院模板**，别拿学位论文的版式硬套。

## 1. 开工前必须问清的四件事

| 必须问 | 为什么 | 默认 |
|---|---|---|
| **博士还是硕士？** | 封面称谓、内封“博士研究生/硕士研究生”、成果页标题都随之变 | 不问不写 |
| **学术学位还是专业学位？** | 封面第二行“（学术学位论文）/（专业学位论文）”；专硕常有企业导师、实践环节章节 | 学术学位 |
| **理工类还是人文社科类？** | 正文层次编号完全不同（`第1章/1.1/1.1.1` vs `第一章/一、/（一）/1.`），选错整篇重排 | 按学院/学科判，判不准就问教学秘书 |
| **学院有没有另外发模板或字数要求？** | 学院模板优先级最高；部分学院对章节数、图表数、外文文献比例有额外规定 | 按本规范 |

再确认：题目（中英文）、学科、导师、学院、答辩日期、密级。

## 2. 全文骨架：每章都要闭环

范例里每一章都是同一个套路，照着搭不会散：

```
第1章  绪  论
  1.1  课题背景及研究的目的和意义
  1.2  ××领域的研究进展（分 1.2.1 / 1.2.2 / …）
  1.3  ××关键问题（或理论基础的不足）
  1.4  本文的主要研究内容
第2章  …（理论 / 模型 / 方法）
  2.1  引言
  2.x  具体内容
  2.n  本章小结
第3～N章  …（每章一个完整研究单元）
  3.1  引言      ← 交代“上一章留下了什么，这章解决什么”
  3.x  …
  3.n  本章小结   ← 只写本章结论，不重复前文，不预告下一章
结  论
参考文献
攻读博士学位期间取得创新性成果
声明 / 致谢 / 个人简历
```

**硬规则三条**：

1. 第 1 章不叫“引言”，叫“绪论”；其余各章第一节叫“引言”，最后一节叫“本章小结”。缺“引言/本章小结”的章在盲审里会被指“结构不完整”。
2. “本章小结”只收本章结论（1～3 条），不写“综上所述”式复述。
3. 章数按研究单元算，不为凑章数把一章拆两半；硕士一般 4～5 章，博士 5～7 章（经验值，以学院要求为准）。

## 3. 绪论怎么写

绪论是盲审第一个被挑的地方，四块内容别混：

| 小节 | 写什么 | 常见错误 |
|---|---|---|
| 课题背景及研究的目的和意义 | 从**工程/社会需求**切入，落到“为什么必须解决这个问题”，最后一句点明本文目的 | 从学科发展史写起，三段之后还没出现本文要解决的问题 |
| 研究进展（综述） | **按技术路线分组**，不按时间流水账；每组写完给一句“该路线解决了什么、局限在哪” | 逐篇罗列“A 做了…B 做了…”，没有归纳，没有评价 |
| 存在的问题 | 从综述里**收敛**出 2～3 个待解决问题，与后文章节一一对应 | 问题与后文章节对不上，读完不知道每章为何存在 |
| 本文的主要研究内容 | 逐条列出本文做了什么，**每条对应一章** | 写“本文研究了××”这种没有动作的句子 |

综述里的引用用上角标顺序编码，一句多篇写成 `[3,5-7]`。

## 4. 正文各章怎么写

- **引言**：三句话起手——上一章/领域现状留下了什么缺口、本章要解决什么、本章怎么组织。不要复制绪论。
- **方法/模型章**：假设 → 建模 → 求解 → 验证。假设要写“为什么可以这样假设”，验证要给出误差或对比。
- **实验/仿真章**：装置与试样 → 测试方法与工况 → 数据 → 误差与不确定度分析 → 与理论/仿真对比。**数据必须真实**，异常点要解释，不能悄悄删。
- **图表**：每张图表在正文里都要被“叫到”（“如图3-2所示”），且图表本身要能自明（脱离正文也看得懂）。
- **公式**：首次出现的物理量必须给“式中”注释；符号全文统一，别同一符号两处含义。

## 5. 结论怎么写

范例的结构是三段式，照抄结构不照抄话：

```
1. 一句话总括：本文围绕××问题，采用××方法，完成了××。
2. 创造性工作（逐条编号，3～5 条）
   1. 建立了……模型，可……（给出可验证的效果，如“预测误差＜8%”）
   2. 提出了……方法，相比……提升……
3. 不足与后续研究
   1. 本文仅考虑了……，后续可……（写真实局限，不写“受限于时间”）
```

- 创造性工作**必须与章对应**，每条能指回具体某章。
- 不写“首次”“填补空白”“国际领先”这类无法证实的表述。
- 结论不引新文献、不出现新数据。

## 6. 人文社科类的差异

层次编号换成 `第一章 / 一、 / （一） / 1.`，章节组织换成论证式：

```
第一章  绪  论
  一、问题的提出
     （一）课题来源
     （二）研究背景
  二、研究的目的及意义
  三、文献综述
  四、研究方法与技术路线
第二章  …（概念界定 / 理论框架）
第三章  …（现状与实证）
  一、…
     （一）…
        1. 认知风险
  四、本章小结
结  论
```

- 质性材料（访谈、田野、文本）引用要给出**编码或出处**（范例用 `（0A07）` 这类编号），不能只写“有受访者表示”。
- 定量部分交代样本来源、抽样方式、量表信效度。
- 理论框架章必须回答“用这套理论解释本文对象，比别的理论好在哪”。

## 7. 成果页怎么写

| 项 | 要求 |
|---|---|
| 标题 | 攻读博士学位期间取得创新性成果（硕士改“硕士”） |
| 分类 | 理工类用（一）（二）（三）三个序号：发表的学术论文 / 申请及已获得的专利 / 参与的科研项目及获奖情况；人文社科类用一、二、三、四四个序号：发表的学术论文 / 发表的国际会议论文 / 参与的专著 / 参与的课题项目 |
| 每条附注 | 收录号（SCI/EI、IDS 号、IF）与**对应论文第 X 章**；专利写申请号与状态（已受理/已授权） |
| 底线 | 只列**已发表/已录用/已申请**的，在投的注明“under review”；不编卷期页码，不把参与写成主持 |

## 8. 和课程报告、大创的根本区别

| 维度 | 课程报告 / 大创 | 研究生学位论文 |
|---|---|---|
| 篇幅 | 2000～10000 字 | 硕士 3～5 万字、博士 8～15 万字（经验值，以学院要求为准） |
| 结构 | 按评分点搭 | 固定骨架，章章闭环（引言 + 本章小结） |
| 题注 | 中文单语 | **中英双语**，图题在下、表题在上 |
| 层次 | 一、（一）1. 或 1. 2. 3. | 理工 `第1章/1.1/1.1.1`，人文 `第一章/一、/（一）/1.` |
| 前置件 | 封面 | 封面 + 中英内封 + 中英摘要 + 中英目录 |
| 后置件 | 参考文献 | 结论 + 参考文献 + 成果 + 声明 + 致谢 + 简历 |
| 审查 | 任课教师 | 查重 + 盲审 + 答辩；形式审查不过直接退回 |

## 9. 盲审与形式审查的常见扣分点

| 扣分点 | 具体表现 |
|---|---|
| 结构与内容不符 | 绪论列了 4 个问题，正文只有 2 章对应 |
| 综述像流水账 | 按时间罗列文献，无分组、无评价、无缺口 |
| 图表不规范 | 双语题注缺失、图题在图上方、表格有竖线、编号不按章 |
| 参考文献问题 | 只列不引、引而不列、格式不统一、卷期页码缺失、外文文献过少 |
| 摘要不合格 | 写成目录；中英文内容不一致；关键词与正文术语不符 |
| 结论空泛 | 没有可验证的创造性工作，或创造性工作与章节对不上 |
| 格式硬伤 | 页眉奇偶页不对、目录手打页码、声明页代签、页码断续 |
| 语言 | 口语化、长句套长句、同一概念多个译名 |

## 10. 交付清单

- [ ] 学位层次、学位类型、学科门类三项确认无误（决定称谓与编号体系）
- [ ] 结构完整：封面 → 中英内封 → 摘要 → Abstract → 目录 → Contents → 正文 → 结论 → 参考文献 → 成果 → 声明 → 致谢 → 简历
- [ ] 每章都有“引言 + 本章小结”
- [ ] 绪论列的问题数 = 正文对应章节数
- [ ] 结论的创造性工作逐条可指回具体章节
- [ ] 图表全部双语题注、按章编号、正文都有提示语
- [ ] 参考文献全部真实、格式统一、与正文上角标一一对应（走 `[@key]` 对账）
- [ ] 成果页只列已发表/已录用/已申请，附收录号与对应章节
- [ ] 声明页签名与日期留空手签
- [ ] 中英文摘要内容一致，关键词对得上
- [ ] 全文标点全角、引号中文、无英文直引号
- [ ] 查重前自查：连续引用是否过长、是否有未标注的转述
