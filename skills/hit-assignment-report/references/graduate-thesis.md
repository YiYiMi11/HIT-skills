# 研究生学位论文 / 实践成果（硕士 · 博士）

依据哈尔滨工业大学研究生院 **2025 年 3 月**《研究生学位论文写作指南》与《研究生实践成果写作指南》（各有理工类、人文社科类一份），版式细节对照 2021 年《研究生学位论文书写范例》。原件在 `templates/graduate-thesis/`。

排版细则见 [`../../hit-standard-word-type/references/graduate-thesis-format.md`](../../hit-standard-word-type/references/graduate-thesis-format.md)。

## 0. 覆盖范围

| 交付物 | 覆盖 |
|---|---|
| 学位论文本体（硕士 / 博士，学术学位 / 专业学位） | ✅ 结构、字数、各章写法、结论、成果页、评阅人页 |
| **实践成果**（专业学位，调研报告 / 案例分析 / 产品设计 / 方案设计等） | ✅ 内容定位与写法差异 |
| 开题报告、中期检查、预答辩、盲审材料 | ❌ 指南未覆盖，走学院模板 |

## 1. 开工前必须问清的五件事

| 必须问 | 为什么 | 默认 |
|---|---|---|
| **博士还是硕士？** | 字数、摘要字数、图表是否双语、页眉奇偶、结论结构、文献数量**六项**全变 | 不问不写 |
| **学术学位还是专业学位？** | 封面第二行选“（学术学位论文）/（专业学位论文）”；专业学位还多一个分叉（见下一行） | 学术学位 |
| **学位论文还是实践成果？**（仅专业学位） | 专业学位可提交实践成果代替论文，成果形式是调研报告、案例分析、产品设计、重大装备、软件产品等，写法完全不同 | 学位论文 |
| **理工类还是人文社科类？** | 层次编号不同（`第1章/1.1` vs `第一章/一、`）；文献数量也不同（40/100 vs 50/120） | 按学科判 |
| **学院有没有另发模板或字数要求？** | 学院模板优先级最高 | 按指南 |

再确认：题目（中英文）、学科或类别、导师（含副导师、行业导师）、学院、答辩日期、密级。

## 2. 硬指标（写之前先对齐，别写完再删）

| 项 | 硕士 | 博士 |
|---|---|---|
| 正文（含图表） | **3 万~5 万字** | **6 万~10 万字** |
| 中文摘要 | 理工 500~1000 字 / 人文 600~1000 字 | 1000~2000 字 |
| 结论 | ≤2000 字，至少“主要结果 + 展望” | ≤2000 字，“主要结果 + 创新点 + 展望” |
| 参考文献 | 理工 ≥40 / 人文 ≥50 篇，外文 ≥1/2，近五年 ≥1/3 | 理工 ≥100 / 人文 ≥120 篇，同比例 |
| 图表题注 | **只用中文** | **中英双语**，中文在上 |
| 页眉 | 单面，固定“哈尔滨工业大学硕士学位论文” | 双面，奇偶不同 |
| 评阅人/答辩委员会名单及答辩决议页 | 不要求 | **必加** |

理工类的适用范围含经济学、管理学门类下的一级学科与专业学位类别。

## 3. 学位论文类型与实践成果（专业学位分叉）

**学位论文类型**（理工类专业学位）：

| 类型 | 层次 | 适用类别 |
|---|---|---|
| 专题研究类论文 | 硕士 | 电子信息、机械、材料与化工、资源与环境、能源动力、土木水利、生物与医药、交通运输 |
| 工程类博士专业学位论文 | 博士 | 工程类博士 |
| 专题研究类 / 案例研究类论文 | 硕士 | 工商管理 |
| 专题研究类论文 | 硕士 | 会计 |

**实践成果类型**（理工类，指南表 1 按序号列出）：

- 硕士（工程类）：调研报告、案例分析报告、产品设计（作品创作）、方案设计
- 博士（工程类）：重大装备、仪器设备、硬件产品、软件产品、设计方案、技术标准、案例分析报告
- 硕士（会计）：调研报告、方案设计、产品设计

走哪条由学院与导师定。**问清楚再动笔**——实践成果的章节骨架和论文不是一回事。

## 4. 全文骨架：每章都要闭环

```
第1章  绪  论
  1.1  课题背景及研究的目的和意义
  1.2  ××领域的研究进展（1.2.1 / 1.2.2 / …）
  1.3  存在的问题（收敛成 2~3 条）
  1.4  本文的主要研究内容
第2章  …（理论 / 模型 / 方法）
  2.1  引言
  2.x  具体内容
  2.n  本章小结
第3~N章  …（每章一个完整研究单元）
  3.1  引言      ← 上一章留下什么缺口、这章解决什么
  3.n  本章小结   ← 只收本章结论，不重复前文
结  论            ← 不带章号
参考文献
攻读□士学位期间取得创新性成果
□士学位论文评阅人、答辩委员会名单及答辩决议   ← 仅博士
原创性声明和使用权限
索  引（可选）
致  谢
个人简历（除全日制硕士外）
```

**硬规则三条**：

1. 第 1 章叫“绪论”，其余各章首节叫“引言”、末节叫“本章小结”。缺了盲审会指“结构不完整”。
2. “本章小结”只收本章结论（1~3 条），不写“综上所述”式复述，也不预告下一章。
3. 章数按研究单元算，不拆章凑数。

## 5. 摘要怎么写（四段，别写成目录）

| 段 | 写什么 | 长度 |
|---|---|---|
| 1 背景与目的 | 背景与意义、领域现状、本文针对的科学问题或实际问题 | **≤400 字**，不宜多 |
| 2 主要研究/实践内容 | 核心问题、开展的工作、方法与手段的合理性与先进性 | 适量 |
| 3 主要创新成果 | 新思想、新观点、新理论、新技术、新方法、新结论 | 重点 |
| 4 理论与实际意义 | 学术价值、应用价值或现实意义 | 简短 |

三条禁令：不标引用编号；不用公式、结构式、图表；不用非常用缩写。留学生英文版须另附 ≥3000 字详细中文摘要。

## 6. 绪论与主体

**绪论四块**：

| 小节 | 写什么 | 常见错误 |
|---|---|---|
| 背景与意义 | 从工程/社会需求切入，落到“为什么必须解决”，末句点明本文目的 | 写了三段还没出现要解决的问题 |
| 研究进展 | **按技术路线分组**，每组收一句“解决了什么、局限在哪” | 逐篇罗列，无归纳无评价 |
| 存在的问题 | 收敛出 2~3 条，与后文章节一一对应 | 与章节对不上 |
| 主要研究内容 | 逐条列出，**每条对应一章**，宜用将来时态 | 直接抄目录 |

**主体各章**：引言三句起手（缺口 → 本章目标 → 本章组织）；方法/模型章走“假设 → 建模 → 求解 → 验证”，假设要说清为什么可以这样假设；实验/仿真章必须交代条件、过程、误差与不确定度，异常点要解释，不能悄悄删。

**实践成果的主体**改写为：实践任务来源与约束 → 方案设计与比选 → 实施过程与验证 → 实际效果与推广价值。别套论文的“方法—实验—讨论”。

## 7. 结论怎么写

```
1. 一句话总括：围绕什么、用了什么方法、做成了什么
2. 主要结果（1）（2）（3）…；博士须加创新点，硕士视情况加
3. 局限与展望
```

- 分（1）（2）（3）条列，用“提出了”“揭示了”“证明了”“应用了”起句
- 措辞准确，不用“大概”“或许”“可能是”；一般不写量的符号，写量的名称
- 结论要有相对独立性，不是各章小结的拼贴；常识性结果、重复他人结果不写进结论
- 不出现新数据、不引新文献

## 8. 人文社科类的差异

层次换成 `第一章 / 一、 / （一）/ 1. / 首先…其次…`，章节组织换成论证式：

```
第一章  绪  论
  一、问题的提出
     （一）课题来源
     （二）研究背景
  二、研究的目的及意义
  三、文献综述
  四、研究方法与技术路线
第二章  …（概念界定 / 理论框架）
第三章  …（现状与实证）
  一、…
     （一）…
        1. 认知风险
  四、本章小结
结  论
```

- 质性材料给**编码或出处**（范例用 `（0A07）` 这类编号），不能只写“有受访者表示”
- 定量部分交代样本来源、抽样方式、量表信效度
- 文献基准比理工高：硕士 ≥50、博士 ≥120；中国古典文、史、哲等以中文资料为主的选题，外文占比要求可放宽

## 9. 成果页怎么写

| 项 | 要求 |
|---|---|
| 标题 | 攻读博士/硕士学位期间取得创新性成果 |
| 内容 | 学术论文、专利、专著、产品、行业标准、研究报告、竞赛获奖等分项列出 |
| 署名 | 须满足学校对成果署名的规定；与论文无关、署名单位不含我校的**不列** |
| 附注 | 格式同参考文献；**页码后注明对应章节**；SCI/EI 标收录号，SCI 标当年影响因子，已录用注明刊源 |
| 底线 | 只列真实成果，不编卷期页码，不把参与写成主持 |

**博士另加一页**：学位论文评阅人、答辩委员会名单及答辩决议——无框线表格，列公开评阅人与答辩委员会成员，无需签名；匿名评审不列评阅人；答辩决议须与答辩材料一致。

## 10. AI 使用与学术规范

- 论文或实践成果中**含 AI 生成、合成的文本、图片、音频、视频、虚拟场景**，须按《人工智能生成合成内容标识办法》做内容标识，逐处标注，不是只在声明里写一句
- 引用他人成果必须标注，不得与自己的工作混写
- 数据必须真实，异常点要解释而非删除
- 声明页手签，不代签

## 11. 盲审与形式审查常见扣分点

| 扣分点 | 表现 |
|---|---|
| 结构与内容不符 | 绪论列了 4 个问题，正文只有 2 章对应 |
| 综述像流水账 | 按时间罗列，无分组、无评价、无缺口 |
| 摘要不合格 | 写成目录；背景超过 400 字；中英文不一致 |
| 图表不规范 | 硕士用了双语、博士只写中文；图题在上；表格有竖线；编号不按章 |
| 页眉页码 | 博士没做奇偶页、硕士做了奇偶页；页码断续 |
| 参考文献 | 数量不够、外文占比不足、无近两年、本人成果混进列表 |
| 结论空泛 | 没有可验证的结果，或与章节对不上；超过 2000 字 |
| 缺页 | 博士漏评阅人页、成果页、声明页 |
| 语言 | 口语化、长句套长句、同一概念多个译名 |

## 12. 交付清单

- [ ] 五问已确认：硕/博、学术/专业、论文/实践成果、理工/人文、学院模板
- [ ] 字数达标（硕 3~5 万、博 6~10 万，含图表）
- [ ] 摘要按四段写、背景 ≤400 字、字数在档内；关键词 3~6 个
- [ ] 每章有“引言 + 本章小结”；绪论列的问题数 = 正文章节数
- [ ] 结论 ≤2000 字、不带章号、博士含创新点
- [ ] 参考文献数量与外文比例达标，全部真实并与正文上角标对应（走 `[@key]` 对账）
- [ ] 图表题注按学位层次（硕士中文 / 博士双语），按章编号，正文有提示语
- [ ] 成果页每条注明对应章节；博士已加评阅人页
- [ ] AI 生成内容已标识
- [ ] 声明页签名日期留空手签
- [ ] 全文标点全角、引号中文、无英文直引号
- [ ] 查重前自查：连续引用是否过长、是否有未标注的转述

## 13. 和本科毕设别混

| 维度 | 本科毕业设计（论文） | 研究生学位论文 |
|---|---|---|
| 篇幅 | ≥1.5 万字 | 硕士 3~5 万、博士 6~10 万 |
| 前置件 | 封面 + 中文内封（无英文内封） | 封面 + 中文内封 + 英文内封 |
| 图表题 | 一律中文 | 硕士中文、**博士双语** |
| 页眉 | 固定一句，不分奇偶 | 博士奇偶不同、硕士固定 |
| 结论 | 400~2000 字，不带章号 | ≤2000 字，博士含创新点 |
| 成果页 | 攻读学士学位期间 | 攻读硕士/博士学位期间 + **博士评阅人页** |
| 参考文献 | ≥15 篇 | 硕士 ≥40/50、博士 ≥100/120 |
| 新增项 | — | 索引、书脊、AIGC 标识、实践成果通道 |

判错这一层的代价最大：本科套研究生会多出英文内封和双语题注，研究生套本科会缺英文内封、评阅人页和成果页。
