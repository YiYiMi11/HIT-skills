# 校级大创（大学生创新训练计划）报告

哈工大本科生院「大学生创新训练计划」（简称大创）的申报与结题文档规范。依据：本科生院《大学生创新训练计划管理办法》（校本〔2024〕61 号）+ 本科生院制式模板（申请书三份、进展报告、验收书）。

## 0. 开工先问清三件事

大创最容易写错的地方不是内容，是**写错赛道、写错阶段**——三份申请书长得像，章节完全不同。

| 必须问 | 为什么 |
|---|---|
| **哪个赛道？** 创新训练 / 创业训练 / 创业实践 | 三者正文骨架、字数上限、封面字段都不同（创业类多企业指导教师、项目类别八个方向） |
| **哪个阶段？** 立项申请 / 中期检查 / 延期进展报告 / 结题验收 | 四份文档各自独立，不能互相顶替 |
| **哪个级别？** 校级 / 省级 / 国家级（国创） | 影响验收书"项目级别"勾选、经费来源与结题要求；级别由学院推荐产生，立项时一般先报校级 |

再确认：项目编号、执行时间、团队成员（3–5 人）、指导教师（≤2 人，须指定第一指导教师）。

## 1. 三类赛道对照

| 项 | 创新训练项目 | 创业训练项目 | 创业实践项目 |
|---|---|---|---|
| 做什么 | 自主完成创新性研究：项目设计、条件准备、实施、研究报告、成果交流 | 团队分角色完成商业计划书、可行性研究、企业模拟运行、创业报告 | 基于创新成果提出有市场前景的产品/服务，真实开展创业实践 |
| 适合 | 以科研训练为主 | 有商业构想、做模拟运营 | 已有产品或实体在运营 |
| 执行时限 | 一般 1 年，不超过 2 年 | 一般 1 年，不超过 2 年 | 不超过 3 年（均不晚于毕业） |
| 指导教师 | 一般 1 位 | 校内 + **企业指导教师** | 校内 + **企业指导教师** |
| 申请书正文 | 7 节（研究导向） | 9 节（商业计划导向） | 12 节（运营与融资导向） |
| 封面额外字段 | 无 | 项目来源（自主研发/他人授权/其他）、项目类别 A–H | 同创业训练 |

**项目类别 A–H**（创业类必勾）：A 农林畜牧食品、B 生物医药、C 化工环境、D 电子信息（软件/网站）、E 电子信息（硬件）、F 材料、G 机械能源、H 服务咨询。

## 2. 立项申请书骨架

### 2.1 创新训练项目申请书

| 章节 | 要求 |
|---|---|
| 一、课题组成员 | 姓名/性别/所在院/年级/学号/身份证号/本人签字 |
| 二、项目简介 | **≤500 字**：想做什么、意义与价值、怎么做、预期困难与结果、特色与创新 |
| 三、申请基础 | **≤300 字**：知识技能与获取途径、相关经验与前期准备、与成员兴趣的关联、合作经验与困难 |
| 正文 1、立项背景 | 意义与价值 → 现存问题 → 现有解决方案综述 → 引出本项目的考虑 |
| 正文 2、研究内容 | 先分解工作，再分条/分块/分步写"研究…/设计…/调查…"；装置类按"设计/制作/调试"写 |
| 正文 3、预期目标 | **中期目标与结题目标分开写**；结题目标要交代成果形式（报告/软件/装置/论文/专利/软著等） |
| 正文 4、特色与创新 | 相对现有方案新在哪，别写"首次""填补空白" |
| 正文 5、实施方案 | 研究路线（鼓励线框图）→ 各部分方法与手段 → 关键点、困难与对策 |
| 正文 6、进度安排 | 以周或月为单位，甘特图或同类图表 |
| 正文 7、经费预算 | 材料费 / 分析测试费 / 差旅运输费 / 资料费，按内容与市场价测算，须给"预算类别 / 主要用途 / 金额"三列 |
| 四、评审情况 | 指导教师意见 + 签名日期（学生不填） |

> 模板里"立项报告正文"夹在"三"和"四"之间，**保持模板原顺序，不要自己重编号**。

### 2.2 创业训练项目申请书

前置：团队成员表、**团队成员创新/创业经历及分工**、**指导教师指导经历及分工**（校内/企业两行）。

| 正文 | 要求 |
|---|---|
| 一、项目简介 | ≤500 字：背景、研发、品牌或服务描述、特点与技术优势 |
| 二、申请基础 | ≤300 字（同上四问） |
| 三、行业及市场分析 | 行业背景、市场需求、目标市场定位、市场前景 |
| 四、市场竞争及营销策略 | 主要竞争对手、营销策略 |
| 五、组织与运营 | 组织结构、角色分工、模拟生产运营计划 |
| 六、财务分析 | 投资概算、财务指标与效益预测 |
| 七、预期目标及对创业能力的培养 | 训练目标 + 能力成长 |
| 八、其它说明 | 媒体报道、产品资料等佐证 |
| 九、项目进度安排 | 周/月为单位，甘特图 |
| 十、申请者承诺 | 签名 + 日期（模板固定文本，不要改） |
| 十一、评审情况 | 校内、企业指导教师分别签意见 |

## 3. 中期检查与进展报告

管理办法：立项在**秋季学期**，**次年春季**中期检查，**秋季**结题验收与优秀项目评选。

| 文档 | 什么时候用 | 写法 |
|---|---|---|
| 《中期检查报告》 | 所有在研项目必须交，并在大创管理系统提交 + 参加学院中期答辩 | 系统内填报；内容对齐申请书中的"中期目标"，写已完成工作、阶段结果、问题与下一步 |
| 《项目进展报告》（附件 7） | **项目延期时**才交，需指导教师签字后报学院 | 五个要点：①按计划执行情况（已完成/未完成）②存在的问题与困难③未按期完成的原因（延期缘由）④经费使用情况⑤下一步计划与预期目标 |

**中期是分水岭**：学院据中期检查结果择优推荐省级、国家级项目；中期检查结束后不再受理成员与题目变更。写中期报告时把"能支撑推荐"的证据（阶段数据、初步成果）放前面。

## 4. 结题验收（项目验收书）

结构：

| 部分 | 内容 |
|---|---|
| 封面 | 项目编号、项目名称、**项目级别（国家级/省级/校级）**、执行时间、负责人、学号、电话、邮箱、院系及专业、指导教师（职称/电话/邮箱/院系） |
| 一、课题组成员 | 同申请书表格 |
| 二、指导教师意见 | 签名 + 日期 |
| 三、学院专家组意见 | 组长签名 + 盖章 + 日期 |
| 四、项目成果 | （一）专利：序号/专利名称/发明人/申请号/备注；（二）论文：序号/题目/作者/刊物名及期号/备注；（三）其它成果：序号/名称/说明。**专利申请书、论文及刊物封皮目录的电子版须作附件报送** |
| 五、项目研究结题报告 | **不少于 3000 字**，9 节（见下） |
| 六、附件 | 专利、论文及其它支撑材料 |

**结题报告 9 节**：1 课题研究目的；2 课题背景；3 课题研究主要内容；4 结论（成果介绍）；5 经费使用情况；6 问题、体会与收获；7 建议；8 结束语与致谢；9 参考文献。

写作要点：
- 第 4 节是重心，成果要与申请书"结题目标"逐条对应，差在哪就说明原因
- 第 5 节经费要与实际支出、票据口径一致（中期后可用 30%，结题合格报销 70%）
- 成果表没有就写"无"，不要编专利号、刊物期号
- 参考文献只列正文引用过的（走 `[@key]` 对账流程）

## 5. 时间线与系统

```
秋季学期：立项申报（系统填报 + 学院立项答辩）→ 校级立项
          ↓ 学院择优推荐 → 省级 / 国家级（以教育部、省教育厅公示为准）
次年春季：中期检查（系统提交中期检查报告 + 中期答辩）
          ↓ 需要延期 → 提交《项目进展报告》+ 指导教师签字（只能延一次，≤1 年）
秋季学期：结题验收（系统提交《项目结题申请书》+ 论文/专利/竞赛证书 → 结题答辩）
          ↓ 优秀项目评选：不超过当年结题项目的 30%，一等奖 ≤10%
```

系统：本科教学管理与服务平台 → 大创计划管理系统（填报、变更、中期、结题、延期都在系统里走）。

## 6. 评审关注点与扣分点

| 赛道 | 评审看什么 | 常见扣分 |
|---|---|---|
| 创新训练 | 选题价值、方法可行、目标可考核、经费合理 | 目标写成"提高能力"这类不可考核的话；研究内容与背景脱节 |
| 创业训练 | 商业逻辑闭环、市场数据真实、财务测算自洽 | 市场分析全是宏观套话、无竞品；财务只有口号没有表 |
| 创业实践 | 已有基础与真实运营数据、风险控制 | 把"计划做的事"写成"已经做成的事"；流水与投入对不上 |
| 结题（全部） | 成果是否支撑立项承诺、材料是否齐全 | 专利/论文栏填了但无附件；结题报告与中期报告重复 |

## 7. 提交清单

- [ ] 赛道、阶段、级别确认无误（封面字段随之变）
- [ ] 团队 3–5 人，身份证号、学号逐字核对
- [ ] 指导教师 ≤2 人，第一指导教师已指定；创业类补齐企业指导教师
- [ ] 字数限制项：项目简介 ≤500 字、申请基础 ≤300 字、结题报告 ≥3000 字
- [ ] 预算三列齐全，金额与合计一致
- [ ] 成果附件齐全（专利申请书、论文 + 刊物封皮目录）
- [ ] 签名、日期、盖章位留空给老师

| 维度 | 大一年度项目（基础学部） | 校级大创（本科生院） |
|---|---|---|

| 组织 | 基础学部 | 本科生院 + 学院，大创管理系统 |
