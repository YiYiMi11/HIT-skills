# 大一年度项目报告（立项 / 中期检查 / 结题）

哈工大基础学部「大一年度项目」专用写作规范。本文件替代 `assignment-types.md` 中对应骨架，其他流程（文献、引用、去 AI 味、对账）照常走。

**触发**：用户提到“大一年度项目”“立项报告”“中期检查报告”“结题报告”“项目结题”。

## 0. 开工先问清三件事

| 问题 | 为什么必须问 |
|---|---|
| 哪个校区？ | 本部（哈尔滨）与深圳校区（HITSZ）的封面字段、章节、字数都不一样，写错直接重做 |
| 哪个阶段？ | 立项 / 中期 / 结题，结构完全不同，不能复用 |
| 有没有学院发的模板文件？ | 有就给官方 .doc/.docx，按模板填；没有就按本文件结构生成 |

字数以学院当年通知为准；本文件写的是模板自带的字数要求，两者冲突时以通知为准。

## 1. 两校区差异（最容易踩的坑）

| 项目 | 本部（哈尔滨） | 深圳校区 |
|---|---|---|
| 封面“专业”字段 | 立项：**专业（类）** + 辅导员 + 学院（部）<br>中期：**专业集群** + 辅导员 + 院系及专业<br>结题：院系及专业（两处） | 立项/中期：**学院**（两处），无辅导员<br>结题：院系及专业（两处） |
| 成员表“所在”列 | 立项：所在专业（类）<br>中期：所在专业集群<br>结题：所在院系 | 三份统一：**所在学院** |
| 中期正文字数 | **2000 字左右**，五小节 | **1500 字左右**，四小节 + 前置基本信息（背景≤200 字、内容与方案≤400 字） |
| 立项正文字数 | 2000 字以上，六部分 | 2000 字以上，六部分（一致） |
| 结题正文字数 | 3000 字左右，六部分 | 3000 字左右，六部分 + **选填**“拟依托本项目继续开展大创” |
| 专家组意见 | 三、项目专家组意见（中期含 3 项勾选） | 四、项目专家组意见（中期含 3 项勾选） |
| 页面要求 | 明确写：A4、页边距各 2cm、网格 46 字×43 行、行距 16 磅 | 只写 A4 + 正文小四宋体；模板实测页边距 2cm |
| 编号栏 | 中期、结题有“编号：” | 无 |

**中期报告是本部和深圳差别最大的一份**：本部五小节 2000 字，深圳拆成“基本信息表（600 字封顶）+ 四小节 1500 字”。写错版本等于白写。

## 2. 三类报告骨架

### 2.1 立项报告（2000 字以上）

| 章节 | 建议占比 | 必须写到的内容 |
|---|---|---|
| （一）立项背景 | 30% | 研究现状（谁做到哪一步）、趋势（往哪走）、研究意义（解决什么问题、对谁有用）。**要有文献支撑**，别写成科普 |
| （二）项目研究内容及实施方案 | 30% | 研究内容拆 3–5 条，每条一句话说清做什么；实施方案写技术路线、用什么方法/工具/平台、怎么验证 |
| （三）进度安排 | 10% | 按月或按阶段列表：时间 + 任务 + 产出物。要和中期检查节点对得上 |
| （四）中期及结题预期目标 | 20% | **分开写**中期目标与结题目标，且写成可考核的形式（做出什么、达到什么指标、交付什么） |
| （五）经费使用计划 | 5% | 分项列：材料费、测试费、资料费等，合计金额与批准经费口径一致 |
| （六）主要参考文献 | 5% | 只列正文引用过的，格式见排版 skill 的著录示例 |

**评审看什么**：题目是不是大一学生一年能做完的（过大扣分）、目标是否可考核、经费是否合理。**别把国家级项目写成大一项目。**

### 2.2 中期检查报告

**本部（2000 字左右，五小节）**

| 章节 | 建议占比 | 必须写到的内容 |
|---|---|---|
| （一）立项背景 | 15% | 压缩版，3–5 句讲清做了什么、为什么做，别整段复制立项报告 |
| （二）项目研究内容及实施方案 | 20% | 同上，重点写**方案有没有调整**，为什么调整 |
| （三）进展情况及初步创新成果 | 35% | 已完成什么（配数据/图/表）、遇到什么困难、怎么解决、下一步计划。**这是全文重心** |
| （四）结题预期目标 | 15% | 与立项时的目标对照，改为“能否按时完成 + 依据” |
| （五）经费使用情况 | 15% | 已支出分项 + 余额 + 后续用途；与实际报销口径一致 |

**深圳（1500 字左右，四小节）**

前置基本信息：立项背景 **≤200 字**、项目研究内容及实施方案 **≤400 字**（模板明确限字，超了要删）。

| 章节 | 建议占比 | 必须写到的内容 |
|---|---|---|
| （一）进展情况及取得的成果 | 40% | 做了什么、得到什么结果，用数据说话 |
| （二）遇到的困难及下一步工作计划 | 25% | 困难要具体（不是“时间紧张”），对应给出解决动作与时间点 |
| （三）结题预期目标 | 20% | 可考核指标 |
| （四）经费使用情况 | 15% | 已支出 / 余额 / 后续用途 |

**两份中期报告的共同扣分点**：把立项报告复制一遍当进展；只写“正在做”没有阶段性结果；困难写成套话；经费和实际不符。

### 2.3 结题报告（3000 字左右）

正文六部分（两校区一致）：

| 章节 | 建议占比 | 必须写到的内容 |
|---|---|---|
| 1、课题背景 | 15% | 问题从哪来、现状如何、本项目要解决哪一点 |
| 2、课题研究内容与方法 | 25% | 内容分条 + 方法/技术路线 + 实验或调研设计，写到别人能复现 |
| 3、研究结果 | 30% | 核心章节。结果分条呈现，配图/表/数据，每条结果回答一个子问题 |
| 4、创新点 | 15% | 相对已有工作新在哪（方法/数据/应用场景）。**别写“首次”“填补空白”这类没证据的话** |
| 5、结束语 | 5% | 结论 + 局限 + 后续方向，3–5 句，不重复摘要 |
| 6、参考文献 | 10% | 只列文中引用过的，格式按排版 skill |

**深圳额外一节（选填）**：拟依托本项目继续开展大学生创新创业训练计划——写后续方向或内容 + 预期成果。不打算继续就整节留空/删除，别硬编。

**评审看什么**：结果是否支撑立项时承诺的目标；创新点是否有据；图表是否自明；经费与成果是否匹配。

## 3. 表格与封面字段（生成文档时按此填）

**封面**（两校区通用结构，字段名按校区替换）

哈尔滨工业大学[（深圳）]     ← 一号黑体加粗居中

项目名称：

联系电话：        电子邮箱：
<专业（类）/专业集群/学院>：   [辅 导 员：]

**成员表**（表头五号宋体居中）

| 姓名 | 性别 | 所在<专业（类）/专业集群/院系/学院> | 学号 | 联系电话 | 本人签字 |
|---|---|---|---|---|---|

**结题“项目成果”表**：序号 | 名称 | 说明（论文/专利/软著/实物/获奖，说明里写清本人贡献与状态）。

**签章位**：指导教师意见处留“签名 + 年月日”；专家组意见处留“组长签名 + （学部盖章）+ 年月日”；本部立项另有“批准经费：____”。

## 4. 引用与文献量

- 引用照常只用 `[@key]`，由 `refs_audit.py` 渲染，禁止手写编号。
- 文献量：立项 8–15 篇，中期 8–15 篇（含立项时已引的），结题 15–25 篇。
- 背景部分必须引，方法部分引同类做法，结果讨论部分引对比数据。

## 5. 交付前多查一遍

- [ ] 校区对了：封面字段、成员表列名、中期字数三处都对
- [ ] 阶段对了：立项不写“已取得成果”，结题不写“计划开展”
- [ ] 字数达标（本部中期 2000 / 深圳中期 1500 / 结题 3000，±10%）
- [ ] 进度安排与中期节点、结题时间自洽
- [ ] 经费：计划/已支出/余额口径一致，合计对得上
- [ ] 图表有编号、有标题、正文有“如图 X 所示”
- [ ] 正文自建表格用三线表（顶线/栏目线/底线，无竖线）；模板固定的成员表、成果表保留原框线
- [ ] 中文标点全角，引号用“”‘’，全文无英文直引号
- [ ] 参考文献全部来自 `refs.json`，与正文引用一一对应
- [ ] 封面无空缺项（含编号、日期、批准经费）
