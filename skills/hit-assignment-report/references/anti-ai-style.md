# 去 AI 味写作规则

## 先明确一件事

没有任何方法能**保证**过 AIGC 检测。检测工具（知网 AIGC、维普、Turnitin）测的是文本的统计特征——困惑度、句长方差、用词分布。我们能做的是**让文本特征更像人写的**，不是"破解检测"。

真正有效的一招不是改写，是**掺进只有你能写的东西**：实验记录、课堂笔记、你踩过的坑、具体到型号和参数的细节。这部分占比越高，整篇越安全。目标：人写成分 ≥30%。

---

## 一、禁用清单（出现就要改）

### 套话连接词

| 禁用 | 改成 |
|---|---|
| 首先 / 其次 / 最后 | 直接用内容推导；或"先说…"/"更关键的是…" |
| 综上所述 / 总而言之 / 总的来说 | 直接给结论句，不要导航词 |
| 值得注意的是 | 删掉，直接说那件事 |
| 不难发现 / 显而易见 / 众所周知 | 删掉。真显而易见就不用写 |
| 随着社会的发展 / 随着科技的进步 | 换成具体时间+具体事件："2023 年国内储能装机翻倍之后…" |
| 在当今社会 / 在当今时代 | 删掉 |
| 具有重要的理论意义和实践价值 | 说清楚对谁有用、怎么用 |
| 本文旨在 / 本文试图 / 本文将… | 直接写内容 |

### 句式模板

- **三段式排比**：`第一…第二…第三…`、`一方面…另一方面…`、`其一…其二…`
- **"不仅…而且…"** 堆叠
- **每段结尾都总结**：人写东西不会每段都收口
- **每段长度相近**：这是最强的 AI 特征，`style_lint.py` 会算变异系数

### 标点习惯

- 破折号 `——` 少量用（全文 ≤3 处），AI 爱用它做插入解释
- 少用分号串长句
- 中文引号统一（`""` 或 `「」`，按课程习惯，全篇一致）

## 二、要做的事（正面清单）

### 1. 句长必须长短交错

AI 的句子集中在 25–45 字。人写的会有 8 字的短句。

❌ 均匀：
> 锂离子电池在过充条件下会因内部产热速率超过散热速率而进入热失控状态，这一过程伴随着电解液的分解与气体的剧烈释放。

✅ 交错：
> 过充时内部产热快过散热，电池就进了热失控。电解液分解、产气、内压升高，几百毫秒内完成。

### 2. 段落长度要有方差

有的段落 2 句，有的段落 8 句。短段用来强调或转折：

> 这里有个反直觉的地方：温度升高不一定先触发预警,有时电压先塌。

一句话成段，是典型的人写痕迹。

### 3. 具体化：数字、型号、时间、地点

❌ "实验效果显著提升"
✅ "充电时间从 42 min 降到 31 min，能量效率从 89.2% 提到 93.5%"

❌ "采用了某型号传感器"
✅ "用 DS18B20，±0.5℃ 精度，采样周期 1 s"

**前提是数据真实**。编数字比写空话更危险。

### 4. 掺入第一人称的操作痕迹

实验类、调研类必须有：

> 第一次测量时忽略了环境温度的影响，三组数据偏差都在 8% 以上。加上恒温箱后重测，偏差降到 1.2% 以内。

> 问卷第 7 题原本设成单选，预调研时有 6 位受访者要求多选，正式发放时改成了多选。

这种句子 AI 写不出来，因为它没有"过程"。

### 5. 承认局限，保留失败

> 本文的样本集中在哈尔滨三所高校，结论能否推广到其他地区存疑。

> 该方案在低温下（<0℃）效果明显变差，这一点在第 4 章没有解决。

### 6. 术语密度要不均匀

有的地方啰嗦解释（因为这里重要），有的地方直接甩术语（假设读者懂）。AI 的术语密度是均匀的。

### 7. 允许"不完美"的表达

人写东西会有：
- 稍长的过渡句（"说完机理，再来看具体怎么预警——这两件事其实是一回事"）
- 口语化的转折（"这里其实有个坑"）
- 自我修正（"更准确地说，应该是…"）

不要为了"工整"把这些磨掉。

---

## 三、改稿的正确顺序

**不要**写完再全局润色——那样改出来是"AI 文本 + 同义词替换"，痕迹更重。

正确做法：

1. **写作时就按上面的规则写**（60% 的活在这一步）
2. 跑 `style_lint.py` 看命中了什么
3. **按结构改，不按词改**：
   - 段落太均匀 → 拆一个长段成两段，合并两个短段
   - 全篇长句 → 挑 5 处改写成短句
   - 每段都总结 → 删掉 2/3 的段末总结句
4. 再跑一次，直到无 FAIL

---

## 四、降 AIGC 检测率的额外手段

| 手段 | 效果 | 风险 |
|---|---|---|
| 增加具体数据、参数、案例 | 高 | 数据必须真实 |
| 加入个人观察/操作过程 | 高 | 无 |
| 打乱段落长度分布 | 中高 | 无 |
| 引用真实文献原句（加引号） | 中 | 引用比例过高会拉高重复率 |
| 替换同义词 | **低** | 无，但也基本没用 |
| 加错别字/病句 | 低 | 老师会扣分 |
| 用翻译软件来回翻 | 低 | 语句会变僵硬，反而更像机翻 |

**结论**：投入在"具体内容"上，不要投入在"文字伪装"上。

---

## 五、每篇必做的三处人工痕迹

写完检查有没有这三样，没有就补：

1. **一处具体的失败或意外**（"第二组数据明显偏离，排查后发现是…"）
2. **一处个人的判断**（"笔者倾向于认为 X 派更有解释力，因为…"）
3. **一处带时间地点的细节**（"2026 年 3 月在实验室实测时…"）

这三处是任何检测工具都学不会的。
