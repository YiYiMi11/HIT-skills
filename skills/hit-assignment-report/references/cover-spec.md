# 封面与版式

## 一、优先级：老师模板 > 通用封面

**第一步永远先问：老师有没有发模板？**

- 发了 → 严格套用，一个字段都别改，只填内容
- 没发 → 用下面的通用封面
- 学院有统一格式（如某些学院要求中英文封面）→ 按学院

套用老师模板时用 `workbuddy-local-office-edit` 打开模板直接填，**不要重新生成一个**——重新生成必然破坏页边距、字体、行距。

## 三、封面之后的结构

按作业类型和老师要求取舍，常见顺序：

```
封面（单独一页，无页码）
摘要 + 关键词（单独一页；短作业可省）
目录（≥8 页的作业才需要，单独一页）
正文（从第 1 页起编页码）
参考文献（另起一页）
附录（问卷、代码、原始数据；可选）
```

## 四、页码规则

- 封面**不编页码**
- 摘要、目录用罗马数字 Ⅰ Ⅱ Ⅲ 或单独编号
- 正文从 1 开始
- 页脚居中

## 五、生成方式

用 `workbuddy-docx` 生成 .docx 时：

1. 封面单独一节（`section break`），取消“链接到前一节”再设页码格式，避免正文页码串到封面
2. 所有字体显式设置，不要依赖「正文」样式的继承
3. 数字和英文用 Times New Roman，中文用宋体/黑体——**中英混排必须分设字体**（`w:rFonts` 的 `ascii` 与 `eastAsia` 分别设置）
4. 生成后必须打开确认，不要交付未验证的文件

## 六、常见错误

| 错误 | 后果 |
|---|---|
| 用空格对齐标签 | 换字体后全错位 |
| 封面有页码 | 显得不专业，且老师会指出来 |
| 题目带句号 | 规范里题名不加标点 |
| 中英文字体没分开设 | 数字变成宋体，很显眼 |
| 学号用了全角数字 | 明显外行 |
| 日期写成 2026.10.28 | 应按 2026 年 10 月 28 日 或 2026-10-28 统一 |
