# 封面与版式

## 一、优先级：老师模板 > 仓库原件 > 通用封面

**第一步永远先查有没有现成模板**，顺序是：老师/学院当次发的 → `templates/` 里的学校原件 → 本文件的通用封面。

- 老师发了 → 严格套用，一个字段都别改，只填内容
- 仓库有对应原件（毕设开题/中期、大创申请书、大一年度项目、过程管理记录表等）→ 复制原件填空，见 `../../hit-standard-word-type/references/template-fill.md`
- 都没有（课程报告、学院另发）→ 用下面的通用封面

**封面横线只能来自原件，不许自己画。** 原件的横线是「带下划线的空格 run」，自己敲空格加下划线，五个字段的线右端必然参差不齐；用 `fill_template.py` 填 `P{段}#{run}` 槽位会按原宽度补空格，线长一动不动。表格封面同理：只写 `cell.text`，不增删行列、不重建合并单元格。

套用模板时用 `workbuddy-local-office-edit` 打开直接填，或 `fill_template.py` 批量填，**不要重新生成一个**——重新生成必然破坏页边距、字体、行距。

**本文件只管课程报告。** 下面四类各有自己的封面，不要套这里的字段：

| 文档 | 封面/内封依 |
|---|---|
| 大一年度项目 | `annual-project.md` 第 3 节 |
| 校级大创 | `../../hit-standard-word-type/references/dachuang-format.md` 第 1 节 |
| 本科毕业设计（论文） | `undergrad-thesis.md` + `../../hit-standard-word-type/references/undergrad-thesis-format.md` 第 3～4 节（教务处统一蓝色封面 + 中文内封；题头宋体小1号加粗，页边距上 3.8 / 下 3.0 / 左右 3.0 cm） |
| 研究生学位论文 / 实践成果 | `graduate-thesis.md` + `../../hit-standard-word-type/references/graduate-thesis-format.md` 第 3～5 节（封面 + 中英内封，内封 9 项含副导师/行业导师，页边距上 3.8 / 下 3.0 / 左右 3.0 cm） |

## 三、封面之后的结构

按作业类型和老师要求取舍，常见顺序：

```
封面（单独一页，无页码）
摘要 + 关键词（单独一页；短作业可省）
目录（≥8 页的作业才需要，单独一页）
正文（从第 1 页起编页码）
参考文献（另起一页）
附录（问卷、代码、原始数据；可选）
```

## 四、页码规则

- 封面**不编页码**
- 摘要、目录用罗马数字 Ⅰ Ⅱ Ⅲ 或单独编号
- 正文从 1 开始
- 页脚居中

## 五、生成方式

用 `workbuddy-docx` 生成 .docx 时：

1. 封面单独一节（`section break`），取消“链接到前一节”再设页码格式，避免正文页码串到封面
2. 所有字体显式设置，不要依赖「正文」样式的继承
3. 数字和英文用 Times New Roman，中文用宋体/黑体——**中英混排必须分设字体**（`w:rFonts` 的 `ascii` 与 `eastAsia` 分别设置）
4. 生成后必须打开确认，不要交付未验证的文件

## 六、常见错误

| 错误 | 后果 |
|---|---|
| 用空格对齐标签 | 换字体后全错位 |
| 封面有页码 | 显得不专业，且老师会指出来 |
| 题目带句号 | 规范里题名不加标点 |
| 中英文字体没分开设 | 数字变成宋体，很显眼 |
| 学号用了全角数字 | 明显外行 |
| 日期写成 2026.10.28 | 应按 2026 年 10 月 28 日 或 2026-10-28 统一 |
