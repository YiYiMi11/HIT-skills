# HIT 报告排版规范

## 概述

本 skill 提供哈尔滨工业大学 Word 报告/论文的完整排版规范，涵盖字体字号、行距、层次结构、三线表、插图与图题、公式编号、参考文献著录、打印装订要求。执行 Word 排版任务时必须逐条遵循。

`references/` 下有四份**专用规范**（大一年度项目、大创、研究生学位论文、本科毕业设计）与一份**通用规范**；专用规范优先，通用规范兜底。下面第二张表用于判定该读哪一份。

## 第 0 步 · 先问清楚，再动文件（硬闸门）

**接手排版任务，第一个动作是问，不是改。** 五问一次问全，见 `references/intake.md`：

1. 这是什么文档（课程报告 / 年度项目 / 大创 / 本科毕设 / 研究生学位论文）
2. 哪一支（校区 / 赛道 / 阶段 / 硕博 / 学科门类）
3. 用哪份版式（`templates/` 原件 / 老师这次发的 / 都没有按规范自建）
4. 改到什么程度（只改格式 / 允许调结构 / 连内容一起补）
5. 怎么交付（改原文件 / 另存新文件 / 要 PDF）+ 文件名

规则：

- **未确认前只读不写**：可以打开文档看结构、列问题清单，不许保存、覆盖、“先改两处给他看看”
- 用户一句话已说清 → 跳过提问，但**先复述「规范归属 + 版式来源 + 改动范围 + 交付文件名」**再动手
- 用户说“你定 / 随便” → 按默认值（有原件用原件、只改格式、另存新文件）执行，交付说明里列出假设
- 不许边改边问，不许一次只问一个问题，不许凭文件名猜规范（大创申请书 ≠ 大一年度项目）

反例：上来就调字体字号、按“看起来像”选规范、改完才问“这样可以吗”。

## 铁律：有原件就填原件，不新建版式

`templates/` 里有对应文档的学校原件时，**默认走「复制原件 → 原地填空」，不新建封面、不重绘表格、不自己敲下划线空格**。原因只有一条：封面横线是带下划线的空格 run，自己画必然长短不一；表格合并单元格重建必然错位。

```bash
cp "<templates>/本科毕业论文（设计）开题报告.docx" 交付-开题报告.docx
python3 scripts/fill_template.py inspect 交付-开题报告.docx        # 看槽位号
python3 scripts/fill_template.py fill 交付-开题报告.docx 交付-开题报告.docx --map 封面.json
```

槽位语法、宽度换算、文本框封面的处理、校验清单，全在 `references/template-fill.md`。三条硬规则：

1. `templates/` 只读，永远复制到工作目录再改。
2. 封面字段只填下划线空位（`P{段}#{run}`），按原宽度补空格，横线右端不许移动。
3. 正文段落格式克隆**占位段**（`after:P25@24`），不许克隆标题的黑体格式。

原件缺失（学院另发、课程报告无模板、研究生开题/中期未内置）时才自建版式，并在交付说明里写明「无学校原件，按规范生成」。

## 先判断用哪套规范

| 场景 | 依据文件 |
|---|---|
| 课程论文、实验报告等通用 HIT 报告/论文 | `references/formatting-spec.md` |
| **大一年度项目**立项 / 中期检查 / 结题报告（本部或深圳校区） | `references/annual-project-format.md` **优先** |
| **校级大创**（创新训练/创业训练/创业实践）的申请书、中期检查报告、项目进展报告、项目验收书 | `references/dachuang-format.md` **优先** |
| **研究生学位论文 / 实践成果**（硕士/博士，理工类或人文社科类） | `references/graduate-thesis-format.md` **优先** |
| **本科毕业设计（论文）**：开题 / 中期 / 结题论文（理工类或人文社科类） | `references/undergrad-thesis-format.md` **优先** |

四套专用模板的规格完全不同，别串用：

- **大一年度项目**：封面**黑体一号（26pt）**、正文小四 12pt、行距固定 16 磅、网格 46×43、一级标题只用“一/1./（1）”
- **校级大创**：封面**宋体加粗小二（18pt）**、字段小四加粗、表头五号、正文小四宋体、行距保持模板原样；四类文档（三份申请书 / 进展报告 / 验收书）各有自己的字段
- **研究生学位论文 / 实践成果**：封面**宋体小1号（24pt）加粗**、A4 上 3.8 / 下 3.0 / 左右 3.0 cm、**硕士图表只用中文题注、博士中英双语**、**博士页眉奇偶不同、硕士单面固定**、章标题段前 1 行段后 0.8 行、理工 `第1章/1.1/1.1.1`、人文 `第一章/一、/（一）/1.`
- **本科毕业设计（论文）**：封面题头**宋体小1号加粗**、题目黑体2号、**图表只用中文题注**、页眉固定“哈尔滨工业大学本科毕业论文（设计）”且**不分奇偶页**、章标题段前 1 行段后 0.8 行（不是 20 磅）

**两句话记住优先级**（适用于四套专用模板）：

1. **模板写明的 → 以专用规范文件为准**（大一年度项目看 `annual-project-format.md`，大创看 `dachuang-format.md`，研究生论文看 `graduate-thesis-format.md`，本科毕设看 `undergrad-thesis-format.md`）。
2. **模板没写清或没提的 → 回落到 `formatting-spec.md`**：三线表线宽（顶/底 1.5 磅、栏目线 0.5–0.75 磅、无竖线）、公式编号与排版、插图编排、目录、物理量斜体与单位正体、数字用法、印刷装订、参考文献著录细节。

学院另发的模板优先级最高：**学院模板 > 专用规范文件 > HIT 通用规范**。两边都没写的，按通用规范最近条款处理，并在交付说明里注明“模板未规定，按 HIT 通用规范处理”。

> 本科毕设有**版式截图**可直接对照看位置与线型：`assets/undergrad-thesis-examples/`（封面、内封、目录、正文层次与续图、三线表、续表）。截图看位置，字号仍以规范文件为准。

## 完整规范

所有排版细则位于 `references/formatting-spec.md`。开始排版前先读取该文件，排版过程中随时对照。关键要求速查（**以下为通用规范口径；四份专用规范另有规定的，从其规定**——例如本科毕设与研究生论文的章标题是段前 1 行、段后 0.8 行，不是 20 磅）：

| 元素 | 规范 |
|------|------|
| 章标题 | 黑体小2号，多倍行距1.25，段前20磅，段后10磅，居中，序号如“第1章” |
| 节标题 | 黑体小3号，段前0.5行，段后0.5行，题序顶格，与标题空1字符 |
| 条标题 | 黑体4号，段前0.5行，段后0.5行 |
| 款、项标题 | 黑体小4号，段前0行，段后0行 |
| 正文 | 宋体小4号（数字/英文 Times New Roman），多倍行距1.25，段前0段后0 |
| 插表 | 三线表（顶线/底线约1.5磅，栏目线0.5–0.75磅，无竖线），表题置表上，宋体5号 |
| 插图 | 图题置图下，宋体5号，图序按章编排（图1-1），图前文中须有提示 |
| 公式 | 另起行居中，序号按章编排如“(1-1)”，序号右端对齐 |
| 参考文献 | 顺序编码制，GB/T 7714-2005 著录格式 |
| 标点与引号 | 中文全角标点；双引号“”、单引号‘’；禁用英文直引号；书名用《》（见 §9） |
| 物理量符号 | 斜体（含作下标时）；计量单位符号正体 |
| 目录 | 各章题序及标题黑体小4号，其余宋体小4号 |

## 工作流程

0. **先问清（硬闸门）**：按 `references/intake.md` 五问一次问全，复述「规范归属 + 版式来源 + 改动范围 + 交付文件名」，用户确认后才碰文件。
1. **先查原件**：`templates/` 里有对应文档就复制原件填充（见上节与 `references/template-fill.md`），跳到第 4 步校验；没有原件才进第 2 步。
2. **读取规范**：先读 `references/formatting-spec.md` 获取全部细则；大一年度项目读 `references/annual-project-format.md`，大创读 `references/dachuang-format.md`，研究生学位论文读 `references/graduate-thesis-format.md`，本科毕设读 `references/undergrad-thesis-format.md`，并按其末尾的自检清单核对。
3. **检查文档现状**：读取目标 .docx，识别各级标题、正文、表格、图、公式的当前格式。
4. **逐项应用格式**：按速查表与完整规范逐项设置样式（字体、字号、行距、段前段后、对齐、编号）。
5. **逐项校验**：完成后按以下清单自查：
   - [ ] 各级标题字体字号行距正确，无孤行（题序及标题不得置于页面最后一行）
   - [ ] 中文宋体/标题黑体，数字英文 Times New Roman
   - [ ] 表格为三线表、无竖线，表题在表上且无标点，表序按章编排
   - [ ] 图题在图下，图前有“如图X-X所示”类提示，图不与图题拆页
   - [ ] 公式居中、序号右端对齐、按章编排
   - [ ] 参考文献为顺序编码制、GB/T 7714-2005 格式
   - [ ] 物理量符号斜体、单位正体
   - [ ] 研究生论文另加两组：题注按层次（硕士中文 / 博士双语，图题在下、表题在上）；页眉按层次（博士奇偶不同、硕士单面固定）
   - [ ] 本科毕设另加两组：图表**只用中文题注**；页眉固定“哈尔滨工业大学本科毕业论文（设计）”、不分奇偶页、带粗细双线
   - [ ] 用模板填充的：封面各字段横线右端在同一竖直位置、文字不压线不折行；表格行列数与原件一致；正文未继承标题的黑体格式
   - [ ] 开工前五问已答、已复述并得到确认；交付文件名带日期与版本字母，旧版未被覆盖

## 字体检查与回退

规范要求 宋体、黑体、Times New Roman。排版前先确认系统是否具备这些字体；宋体/黑体/Times New Roman 是商业授权字体，本 skill 不随包分发原字体，而是内置开源替代：

| 规范字体 | 内置替代（assets/fonts/） | 说明 |
|----------|---------------------------|------|
| 宋体 SimSun | NotoSerifSC.ttf（思源宋体同源） | 可变字重，覆盖常用汉字 |
| 黑体 SimHei | NotoSansSC.ttf（思源黑体同源） | 可变字重 |
| Times New Roman | LiberationSerif-*.ttf | 度量兼容，版式不跑位 |

处理流程：

1. 检查目标机器是否已安装宋体/黑体/Times New Roman（Windows 一般自带；macOS 无宋体/黑体）。
2. 若缺失，运行 `bash scripts/install_fonts.sh` 安装内置替代字体（macOS/Linux/Windows Git Bash 均支持）。
3. 在文档中使用替代字体时，同时保留原字体为第一优先：将字体回退链设为 “宋体, Noto Serif SC”（黑体同理为 “黑体, Noto Sans SC”，西文为 “Times New Roman, Liberation Serif”）。装有原字体的机器（如学校打印店）会自动使用原字体，缺字体的机器回退到替代字体。
4. 字体授权与注意事项见 `assets/fonts/README.md`。

## 实现方式

在 WorkBuddy 环境中，Word 文件的读写应通过本地 Office 编辑能力（如 workbuddy-local-office-edit / editor_sdk）完成；在其他环境中可用 python-docx 设置样式。设置段前/段后时注意单位换算：磅值直接用 Pt，“0.5行”用行距单位，多倍行距 1.25 通过 line_spacing 实现。

模板填充用 `scripts/fill_template.py`（python-docx 实现，只写文字不动版式），文本框封面用 editor_sdk 改 `w:txbxContent` 里的文字。
