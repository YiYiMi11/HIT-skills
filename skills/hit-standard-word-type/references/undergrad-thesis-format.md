> **优先级**：学院/教务处当年模板 > 本文件 > `formatting-spec.md`（HIT 通用规范）。

## 0. 先分门类：理工类还是人文社科类

版式完全一样，只有正文层次编号不同。选错要整篇重排。

| 层次 | 理工类 | 人文社科类 |
|---|---|---|
| 章 | `第1章  绪  论` | `第一章  绪  论` |
| 节 | `1.1  课题背景及研究的目的和意义` | `一、问题的提出` |
| 条 | `1.1.1  气体润滑轴承的发展` | `（一）课题来源` |
| 款 | `1.1.1.1  多孔质静压轴承的分类` | `1. 认知风险` |
| 项 | `（1）气体静压轴承` | `首先……其次……再次……最后……` |

人文社科类的第五级不用数字，用“首先/其次/再次/最后”这类文字序。

## 1. 页面设置（范例实测）

| 项 | 值 |
|---|---|
| 纸型 | A4（210 mm × 297 mm） |
| 上边距 | 3.8 cm |
| 下边距 | 3.0 cm |
| 左、右边距 | 各 3.0 cm |
| 版心 | 150 mm × 240 mm ± 2 mm（含页眉、页码），每页约 33 行 |
| 切割后成品尺寸 | 205 mm × 285 mm ± 2 mm |
| 印刷 | **单面**复印或胶印 |

两份范例（理工 11 节、人文 9 节）页面设置完全一致，与指南 3.8 的描述吻合。

## 2. 全文顺序

```
封面（教务处统一模板，含书脊）
内封（扉页，只编中文）
摘  要          ← 独立成页
Abstract        ← 独立成页，中文在前
目  录
正文（第1章 绪论 … 第N章）
结  论          ← 不编章号
参考文献
攻读学士学位期间取得创新性成果
原创性声明和使用权限
致  谢
附录（非必需）
```

装订顺序即上表顺序（实施细则第（三）条存档要求）。前置部分（摘要、Abstract、目录）页码用**罗马数字**单独编排，正文之后用**阿拉伯数字**。

## 3. 封面（指南明示）

2022 版封面是学校统一设计的蓝色封面，**不能自己排版**，须用教务处模板（`templates/undergrad-thesis/本科毕业论文单独封面参考.docx` 与 `封面样例.jpg`）。模板上的文字格式：

| 元素 | 格式 |
|---|---|
| “本科毕业论文（设计）” | **宋体 小1号（24pt）加粗**，居中 |
| 中文题目 | **黑体（中文）、Times New Roman（英文）2号**，居中 |
| 英文题目 | **Times New Roman 2号加粗**，全大写；太长可用小2号 |
| 学生姓名 | 宋体 小2号加粗 |
| “哈尔滨工业大学” | **楷体 小2号加粗** |
| 年、月 | 宋体、Times New Roman 小2号加粗，阿拉伯数字 |

**副题目**：理工类主题目+副题目 ≤35 字，人文社科类 ≤40 字。中文副题目另起一行，用小2号，比主题目退 4 个半角字符后加破折号；英文用冒号连接。除破折号/冒号外不得再有标点。

**书脊**：竖排，黑体小4号，内容是论文题目与“哈尔滨工业大学本科毕业论文（设计）”。

## 4. 内封（扉页，指南明示）

只编中文内封，不编英文内封（这点与研究生学位论文不同）。

左上角：

```
≤毕业论文   ≤毕业设计                    密级：公开
```

用宋体小4号，按实际类型打勾（毕业论文 / 毕业设计）。

其下：

| 元素 | 格式 |
|---|---|
| “本科毕业论文（设计）” | 宋体 小2号加粗，居中 |
| 中文题目 | 黑体、Times New Roman 2号，居中 |
| 七行信息表 | **冒号左侧黑体 4号，冒号右侧宋体 4号，多倍行距 1.5** |

七行固定为（字段名**分散对齐**撑成等宽，冒号对齐后内容左对齐）：

```
本科生：□□□
学号：□□□□□□□□□□
指导教师：□□□教授
专业：□□…□
学院：□□…□
答辩日期：□□□□年□月
学校：哈尔滨工业大学
```

注意：“答辩日期”在范例里排成“答 辩 日 期”（字间距撑开），“学号”排成“学　　　号”；字段名一律四字宽，别用空格硬怼。

## 5. 页眉与页码（指南明示）

| 项 | 规格 |
|---|---|
| 页眉线 | 版心上边线的**粗细双线**（粗线在上，宽 0.8 mm），页眉文字排在**双线之上**；渲染分辨率低时两线贴近，看起来像一条粗线 |
| 页眉文字 | **居中**，小5号宋体，内容固定为“哈尔滨工业大学本科毕业论文（设计）” |
| 奇偶 | **不分奇偶页**，单面印刷，每页同一页眉 |
| 页码 | 版心下边线之下**居中**，形如 `- 1 -`（两侧短横线） |
| 前置部分 | 罗马数字（I、II…），正文从 1 起 |

页码样式在两份范例里不统一：理工范例前置部分是 `- III -`（带短横线），人文范例是 `V`（不带）。**建议统一用带短横线的 `- N -`**，学院模板另有规定时从模板。

页眉不进封面与内封。

## 6. 摘要与关键词（指南明示）

| 元素 | 格式 |
|---|---|
| 题头“摘  要” | **小2号黑体，居中，中间空 2 个半角字符** |
| 正文 | 宋体小4号（英文 Times New Roman 小4号），与题头**隔一行**开始 |
| 页面 | 中英文摘要**各占一页**，中文在前；摘要页**不写论文题目** |
| 篇幅 | 中文摘要 300 字左右 |
| 关键词 | 正文之后**隔一行顶格**书写，3~6 个，中文用分号隔开、英文用逗号隔开；换行缩进对齐；**最后一个关键词后不加标点** |

```
关键词：多孔质石墨；气体静压轴承；渗透率；稳定性

Keywords: porous graphite, gas bearing, permeability, stability
```

英文关键词用小写（专有名词除外），与中文关键词一一对应。

## 7. 目录（指南明示）

| 元素 | 格式 |
|---|---|
| 收录层级 | 章、节、条**三级**（理工 `1.1.1`；人文 `（一）`） |
| 缩进（范例实测） | 章条目顶格；节缩进约 2 个字符；条再缩进约 2 个字符（合计约 4 字符） |
| 章条目 | 黑体 小4号（加粗，与下两级一眼能分开） |
| 其余条目 | 宋体 小4号；数字及符号 Times New Roman |
| 长条目 | 超过一行时提前换行，换行后缩进至相应标题第一个字符处 |
| 页码 | 由域自动生成，右对齐，点线引导 |

目录须包含：摘要、Abstract、物理量名称及符号表（采用国标符号者可略）、正文章节、结论、参考文献、附录、攻读学士学位期间取得创新性成果、原创性声明、使用授权说明、致谢。

## 8. 正文层次与字号（指南明示）

| 层次 | 字体字号 | 行距 | 段前 | 段后 |
|---|---|---|---|---|
| 章标题 | 黑体 小2号（18pt） | 1.25 倍 | **1 行** | **0.8 行** |
| 节标题 | 黑体 小3号（15pt） | 1.25 倍 | 0.5 行 | 0.5 行 |
| 条标题 | 黑体 4号（14pt） | 1.25 倍 | 0.5 行 | 0.5 行 |
| 款、项标题 | 黑体 小4号（12pt） | 1.25 倍 | 0 | 0 |
| 正文 | 宋体 小4号（12pt），数字英文 Times New Roman | 1.25 倍 | 0 | 0 |

- 章序与章名**居中**排；节及以下**题序顶格**，与标题间空 **2 个半角字符**，阐述内容另起一段
- 章标题**上、下行距 10 mm**，节标题 7~8 mm，条标题 6~7 mm，款/项 3~4 mm，正文行距 3~4 mm
- 每章**另起一页**
- 章标题 ≤15 字，不加标点，尽量不用英文缩写
- 各级题序及标题**不得落在页面最后一行**（孤行）

> 注意：章标题的“段前 1 行 / 段后 0.8 行”是本科规范特有的值，**不要**套用通用规范的“段前 20 磅 / 段后 10 磅”。

## 9. 图（指南明示）

```
                    [ 图 ]
图1-1  气体润滑轴承的分类
(a) 气体静压轴承; (b) 气体动压轴承; (c) 气体动静压轴承; (d) 气体压膜轴承
```

| 项 | 规格 |
|---|---|
| 题注位置 | **图下** |
| 语言 | **只用中文图题**（本科不要求英文图题，这点与研究生论文不同） |
| 字体字号 | 宋体 5号；图中文字宋体/Times New Roman 5号（字多可小5号，全图统一） |
| 编号 | 按章编 `图1-1`；图序与图名之间**空 2 个半角字符** |
| 分图 | 分图号用 `（a）（b）`，分图题置于分图之下或图题之下，连续排列用“；”间隔 |
| 图注 | 图注与其他说明置于**图题之上** |
| 续图 | 分图跨页时下页标 `图1-1（续图）`，总图题只出现一次 |
| 前置提示 | 图前正文须有“见图1-1”“如图1-1所示” |
| 分页 | 图与图题不得拆开排于两页 |
| 引用图 | 除正文标注文献序号外，**图题右上角**也要标文献序号 |
| 斜体 | 图中的物理量、符号用斜体 |

## 10. 表（指南明示）

```
表6-1  1号试样渗透率测试数据(温度：T=16 ℃  高度：H=5.31 mm)
```

| 项 | 规格 |
|---|---|
| 题注位置 | **表上**，**居中**排（范例实测：表题与表格同宽居中对齐，不左对齐） |
| 语言 | **只用中文表题** |
| 字体字号 | 宋体 5号；表内文字宋体/Times New Roman 5号（字多可小5号，全表统一） |
| 编号 | 按章编 `表6-1`；表序与表名之间**空 2 个半角字符** |
| 线型 | **三线表**，不加左右边线；三条线：顶线（粗）、栏目线（细）、底线（粗）。三线表不足以表达时可加大栏间距，以清晰为先 |
| 表名 | 不加标点，表名后不加句号 |
| 表头 | 简单明了，尽量不用斜线；两行表头时单位写在第二行，如“流量修正值 M (m³/s) ×10⁻⁴” |
| 单位 | 全表同一单位时移到表头右上角，加圆括号 |
| 空值 | 无数据填 `—`（占 2 个半角字符） |
| 通栏 | 上下或左右相同的单元格合并，禁止“〃”“同上” |
| 表内说明 | 起行空 2 个半角字符，转行顶格，句末不加标点 |
| 续表 | 跨页时在**表格右上角**（右对齐）写 `表6-1（续表）`，**重复表头** |
| 前置提示 | 表前正文须有“见表6-1”“如表6-1所示” |
| 间距 | 表上下与正文之间空一行 |
| 引用表 | 表题右上角标文献序号 |

## 11. 公式（指南明示）

| 项 | 规格 |
|---|---|
| 位置 | 另起行、居中，与周围文字留出距离 |
| 编号 | 按章编，半角括号 `(1-1)`，**右端对齐** |
| 前有文字 | 如“解”“假定”，文字前空 4 个半角字符，公式仍居中 |
| 末尾 | 公式末**不加标点** |
| 式中说明 | 公式下方另起段，“式中”后空 2 个半角字符；变量与释义之间用**破折号“——”**（占 4 个半角字符）连接；转行与破折号后第一个字对齐 |
| 引用 | “见式（1-1）”“由公式（1-1）” |
| 转行 | 优先在等号处转，其次在 + − × ÷ 处转，运算符只写在转行式前 |
| 变量 | 物理量符号斜体；变量下标建议用正体 |

## 12. 引用标注（指南明示，GB/T 7714—2015）

顺序编码制。正文标注置于所引内容**最后一个字的右上角**，小4号字上角标。

| 情形 | 写法 |
|---|---|
| 单篇 | `二次铣削[1]` |
| 多篇同处 | `[7,9,11-13]`，序号间用“，”，连续序号用起讫号 |
| 多次引用同一文献 | 序号后标页码：`[3]101-108` |
| 文中直接说明 | 与正文排齐，小4号：`由文献[8,10-13]可知` |
| 禁止 | 引用标注不得置于各级标题处 |

## 13. 参考文献（指南明示）

| 项 | 要求 |
|---|---|
| 数量 | **不少于 15 篇**，其中外文文献不少于 3 篇 |
| 时效 | 近五年文献不少于总数的 1/3，且须有近两年文献 |
| 来源 | 尽量引原始文献；二次引用时把二次文献与原始文献同时标注 |
| 不宜引用 | 教材、产品说明书、国家标准、未公开发表的研究报告（PB/AD 等著名报告及大公司技术报告除外） |
| 不计入数量 | 网上参考文献与各类标准（须给出准确网址） |
| 本人成果 | 攻读学位期间本人发表的论文不列入参考文献，改列“攻读学士学位期间取得创新性成果” |
| 序号 | 同一篇文章只用一个序号 |

著录格式（GB/T 7714—2015，六类常用）：

```
［1］唐绪军. 报业经济与报业经营［M］. 北京：新华出版社，1999：117-121.
［1］覃睿，田先钰. 从创新潜力到创新成果：一个创新潜力形成与释放模型［J］. 科技进步与对策，2007（2）：148-152.
［1］张佐光，张晓宏，仲伟虹，等. 多相混杂纤维复合材料拉伸行为分析［C］//第九届全国复合材料学术会议论文集（下册）. 北京：世界图书出版公司，1996：410-416.
［1］金宏. 导航系统的精度及容错性能的研究［D］. 北京：北京航空航天大学，1998：60-63.
［1］数字化转型 2.0 时代，未来的人才与组织要如何定义?［EB/OL］(2019-10-24)［2020-01-02］. http://www.chinatradenews.com.cn/....
［1］中国互联网信息中心. 第45次中国互联网络发展情况统计报告［R］. 中华人民共和国国家互联网信息办公室，2020：1.
```

要点：外文作者姓前名后、名用缩写不加点（`KANAMORI H`）；三位以上作者写前三位加“，等”/“, et al”；卷期页码齐全。正文标注用半角 `[1]`、条目序号在两份指南示例里用全角 `［1］`，**以学院模板为准，全文统一**。

## 14. 攻读学士学位期间取得创新性成果（指南明示）

放在参考文献之后、原创性声明之前。

- 书写格式与参考文献相同，**页码后注明该文对应论文的章节序号**
- 分项列出：发表的学术论文 / 申请及已获得的专利 / 参与的科研项目及获奖情况（理工类范例三项）；人文社科类可含 CSSCI、SSCI、专著、课题
- 被 SCI/EI 收录标注收录号；SCI 一般标发表当年影响因子；已录用未发表注明是否 SCI/EI 刊源
- 与论文无关的、署名第二作者以后的不列

## 15. 原创性声明和使用权限（指南明示）

单独成页，内容为两段固定文本：**本科毕业论文（设计）原创性声明** + **本科毕业论文（设计）使用权限**。

- 声明正文含一句关键约定：**“本毕业论文（设计）对使用 AI 工具的情况进行了明确标注”**——用没用 AI、用在哪，要在文中如实标注，不是只在声明上签个字
- 作者签名、导师签名、日期**留空手签**，不要代签、不要贴签名图片
- 电子版可在教务处网站下载（`templates/undergrad-thesis/HIT本科毕业论文原创性声明和使用权限.doc`）

## 16. 附录与装订

- 附录序号用“附录1”“附录2”；**2022 指南明确附录非必需**（旧版撰写规范要求必附一篇外文文献中文译文、不少于 3000 汉字并作为附录1——若学院仍按旧规执行，按学院要求办）
- 可入附录的材料：一手调查资料、问卷与统计表、篇幅过大的推导与图纸、程序清单、原始数据
- 封皮一律用学校统一设计模板打印
- 成品单面印刷、切割装订

## 17. 与旧版《本科生毕业论文撰写规范》的差异

校内流传的旧版《哈尔滨工业大学本科生毕业论文撰写规范》与 2022 版指南多处冲突，**以 2022 指南为准**，学院另有要求时以学院为准：

| 项 | 旧版撰写规范 | 2022 写作指南（现行） |
|---|---|---|
| 著录依据 | GB/T 7714—2005 | **GB/T 7714—2015** |
| 结论字数 | 400~1000 字 | **400~2000 字** |
| 参考文献数量 | 理工 10~15 篇、文科 15~20 篇 | **统一不少于 15 篇** |
| 附录 | 必附外文译文（≥3000 汉字） | **非必需** |
| 成果页 | 无 | **新增“攻读学士学位期间取得创新性成果”** |
| 封面 | 教务处印制封面（黑体2号题、宋体小2号作者） | **2022 校色封面 + 书脊**，题头“本科毕业论文（设计）”宋体小1号加粗 |
| 图表题间距 | 图序/表序与题名空 1 个半角字符 | **空 2 个半角字符** |
| 题目 | ≤25 字、不设副标题 | ≤25 字，**可设副标题**（理工合计 ≤35 字、人文 ≤40 字） |
