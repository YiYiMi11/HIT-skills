# 校级大创文档排版细则

适用于哈工大本科生院「大学生创新训练计划」（大创）：创新训练 / 创业训练 / 创业实践三类项目的**申请书、中期检查报告、项目进展报告、项目验收书**。

## 0. 总原则：在模板上填，不重排

大创四类文档都是学校制式表格（`.doc`），**最优做法是拿到原始模板直接填写**，不乱改字号、不动表格结构、不重设页面。

模板写明的按模板；模板没写或写不清的，回落 `formatting-spec.md`（HIT 通用规范）。冲突顺序：**模板明示 > HIT 通用规范 > 通行惯例**。

> 和大一年度项目最大的区别：**大创封面是宋体加粗小二（18pt）**，不是黑体一号；别把两套模板的封面规格搞混。

## 1. 封面（三类申请书 + 验收书通用）

| 元素 | 格式 |
|---|---|
| 编号 / 项目编号 | 小四（12pt）加粗，左上角（《项目进展报告》为五号加粗） |
| 标题三行：校名 / "大学生创新训练计划" / 文档名 | **小二（18pt）宋体加粗，居中**，三行分别成段 |
| 字段行 | 小四（12pt）加粗，左对齐，冒号后用下划线或空格留填写位 |
| 制表单位 | 小四加粗，居中（本部：哈尔滨工业大学本科生院制 / 本科生院） |
| 填表日期 | 小四加粗，居中，"填表日期：　年　月　日" |

字段按模板固定顺序排列，别自行合并或增删：

```
项目名称：
拟申请经费        元
执行时间：      年   月至     年   月
负责人：          学号：
联系电话：        电子邮箱：
院系及专业：
指导教师：        职称：
联系电话：        电子邮箱：
院系及专业：
```

创业训练 / 创业实践封面多出的内容：**企业指导教师**（另附职称 / 电话 / 邮箱 / **所在单位**）、**项目来源**（□自主研发 □他人授权 □其他）、**项目类别 A–H**（八选一，打勾）。

验收书封面把"指导教师 / 院系及专业"改为**项目级别（国家级、省级、校级）**一行 + 指导教师四行。

## 2. 表格

| 元素 | 格式 |
|---|---|
| 表头 | 五号（10.5pt）宋体，居中 |
| 表体 | 五号宋体，居中；签字列留空手写 |
| 边框 | 模板表格保留原网格框线（成员表、成果表、预算表、评审意见栏） |
| 空缺 | 无内容写"—"或"无"，不留空行、不删行 |

**正文里自己新增的数据表**（结题报告中的统计表、对比表）→ 按 `formatting-spec.md` §5 用三线表：顶线 / 底线 1.5 磅、栏目线 0.5–0.75 磅、无竖线。

成员表列（申请书与验收书一致）：姓名 | 性别 | 所在院 | 年级 | 学号 | 身份证号 | 本人签字。

## 3. 正文填写

| 元素 | 格式 |
|---|---|
| 正文 | 小四（12pt）宋体，数字与英文 Times New Roman |
| 行距 | 与模板一致（模板多为单倍或 1.25 倍），**不要拉成 1.5 倍或 2 倍**撑页数 |
| 段落 | 首行缩进 2 字符；编号层级沿用模板（创新训练用 `1、2、3、`；创业类用 `一、二、三、`） |
| 字数限制 | 项目简介 ≤500 字、申请基础 ≤300 字（模板硬性），超了要删 |
| 图表 | 图题在图下、表题在表上，五号宋体；正文先出现"如图 X 所示" |
| 参考文献 | 五号宋体，顺序编码制，GB/T 7714-2005（回落通用规范 §7） |

图表编号：大创文档没有"章"体系，**全文连续编号**（图 1、图 2、表 1、表 2），不要用"图 1-1"。

## 4. 《项目进展报告》（附件 7）专有格式

| 元素 | 格式 |
|---|---|
| 项目编号 | 五号（10.5pt）加粗 |
| 标题 | 小三（15pt）加粗，格式为"***项目进展报告"（替换为项目名） |
| 五个要点 | 五号（10.5pt）宋体，逐条对应，不要改标题文字 |
| 篇幅 | 模板未限字数；每条 150–300 字，重点写"未完成原因 + 补救动作 + 新时间点" |

五个要点原文：①按计划进度安排执行的情况（已完成的主要工作及未按计划完成的研究内容）；②项目进行过程中存在的问题及困难；③未按计划进度完成任务的原因（延期的缘由）；④经费使用情况；⑤下一步工作计划及预期达到的目标。

## 5. 《项目验收书》结题报告部分

| 元素 | 格式 |
|---|---|
| 标题 | 模板固定"五、项目研究结题报告（注：项目研究报告字数应不少于3000字。）" |
| 九节编号 | 沿用模板：`1、课题研究目的`…`9、参考文献` |
| 正文 | 小四宋体，首行缩进 2 字符 |
| 成果表 | 专利 / 论文 / 其它成果三张表，表头五号居中，备注列写清状态（已受理/已授权/已录用） |
| 附件 | 专利申请书、论文及刊物封皮目录的电子版另附，正文里要有"见附件 X"的指引 |

## 6. 交付前自检

- [ ] 封面标题三行、小二加粗居中；字段行小四加粗；无空缺（含项目编号、执行时间、项目级别）
- [ ] 创业类：企业指导教师四行齐全，项目来源与 A–H 类别已勾选
- [ ] 表格保留模板框线；新增数据表为三线表
- [ ] 正文字体小四宋体、数字英文 Times New Roman；行距未被放大
- [ ] 字数限制项达标（≤500 / ≤300 / ≥3000）
- [ ] 图题在下、表题在上，编号连续
- [ ] 参考文献五号、顺序编码制，与正文上角标一致
- [ ] 签名、日期、盖章位留空给指导教师与专家组
- [ ] 与大一年度项目模板没有串用（封面字体、字段名、文档名逐项核对）
