# 研究生学位论文排版规范（理工类 / 人文社科类）

依据哈尔滨工业大学研究生院 **2025 年 3 月**发布的《研究生学位论文写作指南》（理工类、人文社科类两份）与同名的《研究生实践成果写作指南》，版式细节对照 2021 年《研究生学位论文书写范例》。

- 学位论文写作指南（理工类 / 人文社科类）
- 实践成果写作指南（理工类 / 人文社科类）
- 学位论文书写范例（理工类 / 人文社科类）

原件在 `templates/graduate-thesis/`。

> **优先级**：学院模板 > 2025 指南 > 2021 范例（仅补版式细节）> `formatting-spec.md`。
> **取值来源**逐条标注：**指南明示**、**范例实测**（从范例文件读出的值）、**推定**（指南未写、回落通用规范）。
>

## 0. 三件事先分清

### 0.1 学科门类：理工类还是人文社科类

版式一致，层次编号不同。

| 层次 | 理工类 | 人文社科类 |
|---|---|---|
| 章 | `第1章  绪  论` | `第一章  绪  论` |
| 节 | `1.1  课题背景及研究的目的和意义` | `一、问题的提出` |
| 条 | `1.1.1  气体润滑轴承的发展` | `（一）课题来源` |
| 款 | `1.1.2.1  …` | `1. 认知风险` |
| 项 | `（1）气体静压轴承` | `首先……其次……再次……最后……` |

理工类的适用范围含**经济学门类、管理学门类**下的一级学科与专业学位类别（指南制定说明）。人文社科类指南另有一套字数/文献数量，见下表。

### 0.2 学位层次：硕士还是博士

这一层决定六处硬指标，写错返工：

| 项 | 硕士 | 博士 |
|---|---|---|
| 正文（含图表） | **3 万~5 万字** | **6 万~10 万字** |
| 中文摘要 | 理工 500~1000 字 / 人文 600~1000 字 | 1000~2000 字 |
| 图表题注 | **只用中文** | **中英双语**，中文在上 |
| 页眉 | **单面印刷，固定“哈尔滨工业大学硕士学位论文”，不分奇偶** | 双面印刷，奇偶页不同（奇数页本章题序+标题在右，偶数页校名在左） |
| 结论 | 至少“主要结果 + 展望” | “主要结果 + 创新点 + 展望” |
| 参考文献 | 理工 ≥40 篇 / 人文 ≥50 篇 | 理工 ≥100 篇 / 人文 ≥120 篇 |
| 评阅人、答辩委员会名单及答辩决议页 | 不要求 | **必加** |
| 英文内封 / 英文目录 | 内封与摘要需中英对照 | 内封、摘要、**目录**、图题表题均需中英对照 |

### 0.3 申请方式：学位论文还是实践成果

专业学位申请人可以**写学位论文**，也可以**提交规定的实践成果**（依据《学位法》）。两者版式相同、字数与文献要求相同，区别在内容定位与成果类型。

**学位论文类型（理工类专业学位，指南表 1）**

| 类型 | 层次 | 适用类别 |
|---|---|---|
| 专题研究类论文 | 硕士 | 电子信息 0854、机械 0855、材料与化工 0856、资源与环境 2857、能源动力 0858、土木水利 0859、生物与医药 0860、交通运输 0861 |
| 工程类博士专业学位论文 | 博士 | 工程类博士专业学位 |
| 专题研究类论文 / 案例研究类论文 | 硕士 | 工商管理 1251 |
| 专题研究类论文 | 硕士 | 会计 1253 |

**实践成果类型（理工类，指南表 1 按序号列出）**

| 层次 / 类别 | 可选的实践成果形式 |
|---|---|
| 硕士（工程类） | 调研报告、案例分析报告、产品设计（作品创作）、方案设计 |
| 博士（工程类） | 重大装备、仪器设备、硬件产品、软件产品、设计方案、技术标准、案例分析报告 |
| 硕士（会计） | 调研报告、方案设计、产品设计 |

表中未列的专业学位类别，可按课题实际参考选用。**是否走实践成果由学院与导师定**，写之前先问清。

## 2. 全文顺序

```
封面
内封（中文，博士另加英文内封）
摘  要
Abstract
目  录
Contents（博士必加；硕士按学院要求）

## 3. 封面（指南明示 + 附录 7 看图核对）

**先用学校统一设计的封面模板，不要自己排白底封面。** 2025 指南附录 7 的封面示例是彩色的：

| 部位 | 内容 |
|---|---|
| 底色 | 浅绿，右下压校徽（齿轮 + 1920 + HIT），底部印“哈尔滨工业大学”与日期 |
| 左侧 | 英文标识 + 主楼线稿：博士 `DISSERTATION FOR THE DOCTOR DEGREE`，硕士 `THESIS FOR THE MASTER DEGREE` |
| 中间竖条（书脊） | 博士**棕褐色**、硕士**蓝色**，竖排“哈尔滨工业大学□士学位论文 + 题目 + 作者” |
| 封面正文 | 见下表 |

| 元素 | 格式 |
|---|---|
| “□士学位论文” | **宋体 小1号（24pt）加粗**，居中 |
| 第二行括号 | **宋体 小2号（18pt）加粗**，居中，三选一：**（学术学位论文）/（专业学位论文）/（同等学力人员）** |
| 中文题目 | **黑体（中文）、Times New Roman（英文）2号**，居中 |
| 英文题目 | **Times New Roman 2号加粗**，全大写 |
| 作者姓名 | 宋体 小2号加粗 |
| “哈尔滨工业大学” | **楷体 小2号加粗** |
| 年、月 | 宋体、Times New Roman 小2号加粗，阿拉伯数字 |

封面模板本仓库未收录（各学院与研究生院分别下发）。**没有模板时不要临时拼一个**——先向导师或教学秘书要，或用教务处/研究生院官网下载件；临时拼的白底封面在形式审查会被退。

- 题目一般不超过 **25 个汉字**，中英文对照；不用不常见缩略词、首字母缩写、代号、公式
- 副题目：主题目+副题目合计 **≤35 字**；中文副题目另起一行、小2号、比主题目**退 4 个半角字符**后加破折号；英文用冒号。除破折号/冒号外不得有标点

## 4. 内封（指南明示）

左上角两组标识，宋体、Times New Roman 小4号：

```
国内图书分类号：××××                学校代码：×××
国际图书分类号：××××                密级：公开
```

其下：

| 元素 | 格式 |
|---|---|
| “□士学位论文” | 宋体 小2号加粗 |
| 中文题目 | 黑体、Times New Roman 2号 |
| 信息表 | **冒号左侧黑体 4号，冒号右侧宋体 4号，多倍行距 1.5** |

信息表共 9 项，后两项为可选项：

```
□ 士 研 究 生：□□□            （硕士或博士研究生姓名）
导        师：□□□（副）教授
副   导   师：□□□（副）教授    （无副导师不列）
行业导师：□□…□               （无行业导师不列）
申 请 学 位：□□□士            （学术学位填学科门类，专业学位填专业学位，如“理学博士”“专业学位硕士”）
学科或类别：□□…□             （如“学科：哲学”“类别：翻译”）
所 在 单 位：□□…□            （全日制填学院/学部/校区；非全日制填工作单位）
答 辩 日 期：□□□□年□月
授予学位单位：哈尔滨工业大学
```

英文内封：Times New Roman，**冒号左侧加粗**，格式与中文内封一致。

## 5. 页眉与页码（指南明示）

| 项 | 规格 |
|---|---|
| 页眉线 | 版心上边线加**粗、细双线**，粗线在上，宽 0.8 mm；页眉文字排在双线之上、居中 |
| 页眉字号 | 小5号宋体 |
| **博士** | 双面印；**奇数页**页眉为本章题序及标题（靠右），**偶数页**为“哈尔滨工业大学博士学位论文”（靠左） |
| **硕士** | 单面印；每页页眉固定“哈尔滨工业大学硕士学位论文”，**不分奇偶** |
| 页码 | 版心下边线之下居中，形如 `- 1 -` |
| 前置部分 | 罗马数字（I、II…），正文从 1 起 |

## 6. 摘要与关键词（指南明示）

| 元素 | 格式 |
|---|---|
| 题头“摘  要” | **黑体小2号居中，两字之间空 2 个半角字符**；行距 1.2 倍，段前 1 行、段后 0.8 行 |
| 正文 | 与题头隔一行开始，小4号 |
| 关键词 | 正文后隔一行顶格；3~6 个，中文用分号、英文用逗号；换行缩进对齐；**最后一个不加标点** |
| 页码 | 摘要与 Abstract 各自独立编排 |

摘要按四段写，**不要写成目录**：

1. **背景与目的**——研究工作或实践工作的背景与意义、领域现状、本文针对的科学问题或实际问题；**这部分一般不超过 400 字**
2. **主要研究内容 / 实践内容**——核心问题、开展的工作、方法与手段的合理性与先进性
3. **主要创新成果**——新思想、新观点、新理论、新技术、新方法、新结论
4. **理论与实际意义**——学术价值、应用价值或现实意义

写摘要的三条禁令：不标引用文献编号；不用公式、化学结构式、图表；不用非常用缩写和非公知公用符号。留学生英文版学位论文须另附**不少于 3000 字的详细中文摘要**。

## 7. 目录（指南明示）

| 元素 | 格式 |
|---|---|
| 收录范围 | 中英文摘要、物理量名称及符号表（可用国标符号者略）、全部章/节/条三级标题、结论、参考文献、附录、成果页、原创性声明、使用授权说明、索引（可选）、致谢、个人简历 |
| 中文目录 | 章题序及标题**黑体小4号**，其余**宋体小4号**，数字与符号 Times New Roman |
| 英文目录（Contents） | 章题序及标题 **Times New Roman 小4号加粗**，其余 Times New Roman 小4号 |
| 长条目 | 超过一行提前换行，换行后缩进至该标题第一个字符处 |
| 页码 | 域自动生成，右对齐，点线引导 |

## 8. 正文层次与字号（指南明示）

| 层次 | 字体字号 | 行距 | 段前 | 段后 |
|---|---|---|---|---|
| 章标题 | 黑体 小2号（18pt） | 1.25 倍 | **1 行** | **0.8 行** |
| 节标题 | 黑体 小3号（15pt） | 1.25 倍 | 0.5 行 | 0.5 行 |
| 条标题 | 黑体 4号（14pt） | 1.25 倍 | 0.5 行 | 0.5 行 |
| 款、项标题 | 黑体 小4号（12pt） | 1.25 倍 | 0 | 0 |
| 正文 | 宋体 小4号（12pt），数字英文 Times New Roman | 1.25 倍 | 0 | 0 |

- 章序与章名**居中**；节及以下**题序顶格**，与标题间空 **2 个半角字符**，阐述内容另起一段
- 每章**另起一页**；章标题 ≤15 字，不加标点，尽量不用英文缩写
- 各级题序及标题不得落在页面最后一行（孤行）
- 章上、下行距 10 mm，节 7~8 mm，条 6~7 mm，款/项 3~4 mm，正文 3~4 mm

## 9. 图与表（指南明示）

**先看这一条**：硕士**只用中文**题注，博士**中英双语**（中文在上）。

```
图1-1  气体润滑轴承的分类                      ← 硕士
Fig.1-1  Classification of the gas-lubricated bearing   ← 博士加这行

表6-1  1号试样渗透率测试数据
Table 6-1  Data of measured permeability of sample 1     ← 博士加这行
```

| 项 | 规格 |
|---|---|
| 题注位置 | **图题在图下，表题在表上**，居中；序号与题名之间空 2 个半角字符 |
| 字体字号 | 中文宋体 5号，英文 Times New Roman 5号 |
| 编号 | 按章编 `图1-1`、`表6-1` |
| 线型 | 三线表：顶线、底线粗，栏目线细，**无竖线**；三线表不够用时加大栏间距，以清晰为先 |
| 表头 | 尽量不用斜线；两行表头时单位写在第二行 |
| 单位 | 全表同一单位时移到表头右上角加圆括号 |
| 空值 | 填 `—`（占 2 个半角字符） |
| 通栏 | 相同内容合并，禁止“〃”“同上” |
| 续表 | 表右上角写“表6-1（续表）”，**重复表头** |
| 续图 | 分图跨页时下页标“图1-1（续图）”，总图题只出现一次 |
| 分图 | 分图号用（a）（b），分图题置于分图之下或图题之下，连续排列用“；”间隔 |
| 前置提示 | 图前写“见图1-1”，表前写“见表6-1” |
| 引用图表 | 除正文标文献序号外，**题注右上角**也要标 |
| 斜体 | 图中的物理量、符号用斜体 |

## 10. 公式（指南明示）

| 项 | 规格 |
|---|---|
| 位置 | 另起行、居中，与周围文字留出距离 |
| 编号 | 按章编，`（1-1）`，**右端对齐**，公式末不加标点 |
| 前有文字 | 如“解”“假定”，文字前空 4 个半角字符，公式仍居中 |
| 式中说明 | 另起段，“式中”后空 2 个半角字符；变量与释义用破折号“——”（占 4 个半角字符）连接；转行与破折号后第一个字对齐 |
| 转行 | 优先在等号处转，其次在 + − × ÷ 处转，运算符只写在转行式前 |
| 变量 | 物理量符号斜体；下标建议正体 |

## 11. 引用标注（指南明示，GB/T 7714—2015）

| 情形 | 写法 |
|---|---|
| 单篇 | `二次铣削[1]` |
| 同处多篇 | `[7,9,11-13]`，序号间用逗号，连续序号用起讫号 |
| 多次引用同一文献 | 序号后标页码：`[3]101-108` |
| 文中直接说明 | 与正文排齐、小4号：`由文献［8,10-13］可知` |
| 禁止 | 引用标注不得置于各级标题处 |

标注一律小4号上角标，置于所引内容**最后一个字的右上角**。

## 12. 人工智能生成合成内容标识（指南明示）

学位论文或实践成果中**含 AI 生成、合成的文本、图片、音频、视频、虚拟场景**时，须按《人工智能生成合成内容标识办法》做内容标识。这不是“声明一句就算了”：生成内容本身要标，交付前逐处核对。

## 13. 参考文献（指南明示）

| 项 | 硕士 | 博士 |
|---|---|---|
| 数量 | 理工 **≥40** 篇；人文 **≥50** 篇 | 理工 **≥100** 篇；人文 **≥120** 篇 |
| 外文占比 | 一般不少于总数的 **1/2**（人文类的中国古典文、史、哲等以中文资料为主的选题除外） | 同左 |
| 时效 | 近五年不少于 **1/3**，且须有近两年文献 | 同左 |

- 同一资料只用一个序号；尽量引原始文献，二次引用时原始文献同时标注
- 教材、产品说明书、国家标准、公开发表的研究报告**可以作为参考资料**
- 未公开发表的报告、PB/AD 等内部报告、企业技术报告：引用须经所有权单位同意并办理保密手续；**硕士实践成果不得包含保密内容**
- 网上资料须给准确网址；**本人攻读学位期间发表的成果不列入参考文献**，改列成果页

著录格式（GB/T 7714—2015 六类常用）：

```

## 15. 实践成果的写法（专业学位专用）

版式、页面、字号、页眉、装订与学位论文**完全相同**，差异只在内容定位：

| 项 | 学位论文 | 实践成果 |
|---|---|---|
| 定位 | 学术研究或专业实践的全面总结 | **专业实践工作**的全面总结 |
| 成果形式 | 论文（专题研究类/案例研究类/工程类博士论文） | 调研报告、案例分析报告、产品设计、方案设计、重大装备、仪器设备、硬件/软件产品、技术标准等（见 §0.3） |
| 字数 / 摘要 / 文献 | 硕士 3~5 万、博士 6~10 万；摘要 500/600~1000、1000~2000；文献 40/50、100/120 | **同左** |
| 图表题注 | 硕士中文、博士双语 | 同上 |
| 保密 | 按学院要求 | **硕士实践成果不得包含保密内容** |

实践成果的“主体”章要交代：实践任务的来源与约束、方案设计与比选、实施过程与验证、实际效果与推广价值。别写成学术论文的“方法—实验—讨论”三段式。
