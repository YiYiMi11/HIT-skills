# 研究生学位论文排版规范（理工类 / 人文社科类）

依据哈尔滨工业大学研究生院发布的两份书写范例：

- 《研究生学位论文书写范例（理工类）》<https://hitgs.hit.edu.cn/2021/0513/c17373a317228/page.htm>
- 《研究生学位论文书写范例（人文社科类）》<https://hitgs.hit.edu.cn/2021/0508/c17373a317224/page.htm>

两份范例都是**博士**论文（学术学位）的完整版式示例，覆盖封面 → 内封 → 摘要 → 目录 → 正文 → 结论 → 参考文献 → 成果 → 声明 → 致谢 → 简历的全流程。硕士论文按同一规范换称谓（“博士学位论文”→“硕士学位论文”、“博士研究生”→“硕士研究生”）即可，版式不变。

> **本文件的取值来源分三类，逐条标注，别混用：**
>
> - **范例明示**：范例正文里用“↑（宋体小1号字加粗）”这类批注写死的值 —— 直接照做。
> - **范例实测**：从范例文件的页面设置、版式里读出来的值（如页边距）—— 照做。
> - **推定**：范例没标注、按 `formatting-spec.md`（HIT 通用规范）同源条款补齐的值 —— 照做，但交付说明里注明“范例未规定，按 HIT 通用规范处理”。
>
> 学院若另发模板，**学院模板 > 本文件 > 通用规范**。

## 0. 先分清理工类还是人文社科类

两类的**版式完全一致**，只有正文层次编号不同。这一条选错，整篇标题要重排。

| 项 | 理工类 | 人文社科类 |
|---|---|---|
| 章 | `第1章  绪  论` | `第一章  绪  论` |
| 节（二级） | `1.1  课题背景及研究的目的和意义` | `一、问题的提出` |
| 条（三级） | `1.1.1  气体润滑轴承的发展` | `（一）课题来源` |
| 款（四级） | `1.2.5.1  多孔质静压轴承的分类` | `1. 认知风险` |
| 项（五级） | `（1）气体静压轴承` | `（1）` |
| 图表编号 | 表 6-1、图 1-1（按章编号） | 同（按章编号） |

判定口径：机械、材料、能源、电气、控制、计算机、土木、环境、化工、数学、物理、生命等按理工类；经济、管理、法学、社会学、外语、人文、马克思、设计等按人文社科类。**拿不准就问学院研究生教学秘书**，或看学院往年论文的实际排法。

## 1. 页面设置（范例实测）

两份范例的 10～12 个节设置完全一致：

| 项 | 值 |
|---|---|
| 纸型 | A4（21.0 cm × 29.7 cm） |
| 上边距 | 3.8 cm |
| 下边距 | 3.0 cm |
| 左、右边距 | 各 3.0 cm |
| 版心宽 | 15.0 cm（与通用规范 §8.6 的 150 mm 一致） |
| 装订线 | 0（左侧余量已由 3.0 cm 边距承担） |

页眉、页码都在版心之外，不要为了“放得下”去压缩边距。

## 2. 全文结构顺序

顺序固定，缺一节就是形式审查不过：

```
封面
内封（中文：图书分类号 / 密级 / 题目 / 七行信息）
英文内封（Classified Index / U.D.C / 英文题目 / 七行信息）
摘  要（中文）
Abstract（英文）
目  录
Contents（英文目录）
正文（第1章 … 第N章）
结  论
参考文献
攻读博士学位期间取得创新性成果
哈尔滨工业大学学位论文原创性声明和使用权限
致  谢
个人简历
附录（有则加，位于个人简历之前；无则不加）
```

前置部分（摘要、Abstract、目录、Contents）用**罗马数字**页码 I、II、III…；正文从**阿拉伯数字 1** 重新起算。

## 3. 封面（范例明示）

| 元素 | 格式 |
|---|---|
| “博士学位论文” | **宋体 小1号（24pt）加粗**，居中 |
| “（学术学位论文）” | 宋体 小2号（18pt）加粗，居中；专业学位写“（专业学位论文）” |
| 中文题目 | **黑体 2号（22pt）**，居中 |
| 英文题目 | **Times New Roman 2号（22pt）加粗**；题目过长可用小2号（18pt），全大写 |
| 作者姓名 | 宋体 小2号加粗，居中 |
| “哈尔滨工业大学” | **楷体 小2号加粗**，居中 |
| 年、月 | 阿拉伯数字（如“2020年6月”），宋体、Times New Roman 小2号加粗 |

封面**不放**学号、导师、学院、专业——这些只在内封出现。分类号、密级也不上封面。

## 4. 内封（中文，范例明示）

页首两行左对齐、分列左右：

```
国内图书分类号：××××                学校代码：×××
国际图书分类号：××××                密级：公开
```

四组标识均用**宋体 小4号**。密级按实际填（公开 / 内部 / 秘密 / 机密），不要一律写“公开”。

其下：

| 元素 | 格式 |
|---|---|
| “博士学位论文” | 宋体 小2号加粗，居中 |
| 中文题目 | 黑体 2号，居中 |
| 七行信息表 | **冒号左侧黑体 4号，冒号右侧宋体 4号，多倍行距 1.5** |

七行固定为：

```
博士研究生：□□□
导        师：□□□教授
申请学位：□□博士
学科：机械制造及其自动化
所 在 单 位：机电工程学院
答 辩 日 期：2020年6月
授予学位单位：哈尔滨工业大学
```

字段名用**分散对齐**（“导        师”、“所 在 单 位”）撑成四字宽，别用空格硬怼。右侧内容左对齐、各字段等宽对齐。

## 5. 英文内封（范例明示）

| 元素 | 格式 |
|---|---|
| `Classified Index: ××××` / `U.D.C: ××××` | Times New Roman 小4号 |
| `Dissertation for the Doctoral Degree` | Times New Roman 小2号 |
| 英文题目 | Times New Roman 2号加粗（过长用小2号） |
| 七行信息 | Times New Roman 4号 |

七行固定为：`Candidate` / `Supervisor` / `Academic Degree Applied for` / `Speciality` / `Affiliation` / `Date of Defence` / `Degree-Conferring-Institution`。

## 6. 摘要与 Abstract（范例明示）

| 元素 | 格式 |
|---|---|
| 标题“摘  要” / “Abstract” | 与章标题同级：黑体 小2号居中（**推定**：范例未单独标注） |
| 正文 | 中文 小4号宋体；英文 Times New Roman 小4号 |
| “关键词：” / “Keywords：” | 与正文同字号（小4号），紧接摘要正文之后另起一段 |
| 关键词分隔 | 中文用**分号**`；`，英文用**逗号**`,` |
| 篇幅 | 范例未限字数；以学院要求为准，不要靠堆字数凑 |

英文摘要须与中文摘要**内容一致**，不是逐字直译；语法、用词自己过一遍，机翻痕迹在盲审里很显眼。

## 7. 目录与 Contents（范例明示）

| 元素 | 格式 |
|---|---|
| 标题“目  录” / “Contents” | 黑体 小2号居中（推定，同章标题） |
| 收录层级 | 到**三级**（理工 `1.1.1`，人文 `（一）`） |
| 章条目 | 黑体 小4号（推定：回落通用规范 §8.3），其余宋体 小4号 |
| 页码 | 摘要/Abstract 用罗马数字，正文用阿拉伯数字，右端对齐，点线引导 |
| 自动生成 | 用 Word 的“引用 → 目录 → 自动目录”生成，**不要手打**；手打页码必然对不上 |

Contents 与中文目录条目一一对应，章名用英文（`Chapter 1  Introduction`）。

## 8. 页眉与页码（范例实测 + 推定）

| 项 | 规格 |
|---|---|
| 页眉 | **奇偶页不同**：偶数页“哈尔滨工业大学博士学位论文”，奇数页当前部分标题（`摘  要` / `Abstract` / `目  录` / `第1章  绪  论` / `结  论` / `参考文献` / `个人简历`） |
| 页眉字号 | 中文页宋体 五号；英文页 Times New Roman **小5号**（英文页字号为范例明示，中文页按同档取五号） |
| 页眉横线 | 单细线，贯穿版心 |
| 页码 | 页脚，形如 `- 1 -`（两侧短横线），居中 |
| 页码字体 | 五号，数字 Times New Roman（推定） |
| 前置部分 | 罗马数字 `- I -`、`- II -`…；正文从 `- 1 -` 起 |

奇数页页眉要“随章节变”，做法：每章前插分节符（下一页），取消“链接到前一节”，再改该节页眉文字。

## 9. 正文层次（范例明示）

**理工类**

```
第1章  绪  论                    ← 章序用阿拉伯数字，章名居中，两字间空一格
1.1  课题背景及研究的目的和意义     ← 题序顶格，与标题空 1 字符
1.1.1  气体润滑轴承的发展
1.2.5.1  多孔质静压轴承的分类
（1）气体静压轴承                 ← 项，题序空 2 字符，内容接排
```

**人文社科类**

```
第一章  绪  论
一、问题的提出
（一）课题来源
1. 认知风险
（1）……
```

字号与间距（范例未逐条标注，回落通用规范 §8.2，标为推定）：

| 层次 | 字体字号 | 段前 | 段后 | 行距 |
|---|---|---|---|---|
| 章标题 | 黑体 小2号（18pt） | 20 磅 | 10 磅 | 1.25 倍 |
| 节标题 | 黑体 小3号（15pt） | 0.5 行 | 0.5 行 | 1.25 倍 |
| 条标题 | 黑体 4号（14pt） | 0.5 行 | 0.5 行 | 1.25 倍 |
| 款标题 | 黑体 小4号（12pt） | 0 | 0 | 1.25 倍 |
| 正文 | 宋体 小4号（12pt），数字英文 Times New Roman | 0 | 0 | 1.25 倍 |

正文首行缩进 2 字符；各级题序及标题不得落在页面最后一行（孤行）。

章标题居中、其余层级顶格。章与章之间用**分节符**，不要用连续空行。

## 10. 图（范例明示）

```
                    [ 图 ]
图1-1  气体润滑轴承的分类
Fig.1-1  Classification of the gas-lubricated bearing

(a) 气体静压轴承; (b) 气体动压轴承; (c) 气体动静压轴承; (d) 气体压膜轴承
```

| 项 | 规格 |
|---|---|
| 题注位置 | **图下**，中文题在上、英文题在下，两行 |
| 字体字号 | 宋体、Times New Roman **5号** |
| 编号 | 按章编，`图1-1`、`Fig.1-1`；图序与图名之间空 1 字符 |
| 双语 | **研究生论文必加英文题**，与中文题对应；英文题首字母大写、不加句点 |
| 分图 | 分图号用 `(a)` `(b)`；分图题或说明置于图题**之上**（或紧随图题之下），各项用分号分隔 |
| 前置提示 | 图前正文必须出现“如图1-1所示”“见图1-1”，否则图是孤立的 |
| 分页 | 图与图题不得拆到两页；整页放不下就把图整体移到次页 |
| 引用图 | 注明出处，图题右上角加文献号 |

## 11. 表（范例明示）

```
表6-1  1号试样渗透率测试数据(温度：T=16 ℃  高度：H=5.31 mm)
Table6-1  Data of measured permeability of sample 1
(Temperature: T=16 ℃  Height: H=5.31 mm)
```

| 项 | 规格 |
|---|---|
| 题注位置 | **表上**，中文题在上、英文题在下，两行 |
| 字体字号 | 表题宋体、Times New Roman 5号；表内文字 5号（字多可小5号，全表统一） |
| 线型 | **三线表**：顶线、底线 1.5 磅，栏目线 0.5–0.75 磅，**无竖线** |
| 编号 | 按章编，`表6-1`、`Table6-1`（注意范例英文表序后**不加空格**，`Table6-1`） |
| 表名 | 不加标点、句末不加句号；参数说明可放括号内跟在表名后 |
| 续表 | 跨页时次页写 `表6-1（续表）`，**重复表头**，不重复表名 |
| 单位 | 全表同一单位时移到表头右上角加圆括号 |
| 空值 | 无数据的格填 `—`（占 2 字符宽），不留空白 |
| 通栏 | 同列内容相同用通栏合并，禁止“〃”“同上” |
| 前置提示 | 表前正文出现“见表6-1”“如表6-1所示” |
| 间距 | 表上下与正文之间空一行 |

## 12. 公式（范例明示）

```
                                    (4-1)
式中  d ——多孔质材料的平均粒子直径（m）；
      ε ——孔隙度（孔隙体积占总体积的百分比）；
      K ——特征渗透性或固有渗透性（m²）。
```

| 项 | 规格 |
|---|---|
| 位置 | 另起行、居中；序号右端对齐，按章编 `(4-1)` |
| 序号 | 半角括号，与正文右端齐 |
| 式中说明 | 公式下方另起段，“式中”后空一格；变量与释义之间用**破折号“——”**连接；每条以分号结尾，最后一条用句号 |
| 变量排法 | 转行时与破折号后第一个字对齐；物理量符号**斜体**，单位**正体** |
| 引用 | 正文写“由公式（4-1）”“见式（4-1）” |
| 长公式 | 优先在等号处转行；不行再在 + − × ÷ 处转，运算符只写在转行式**前** |

## 13. 参考文献（范例明示 + GB/T 7714）

顺序编码制，正文上角标 `[3]` 与条目一一对应，**只能列正文引用过的**。

两类的序号括号不同，别串：

| 门类 | 序号写法 |
|---|---|
| 理工类 | 全角方括号 `［1］`，条目内中文用全角标点 |
| 人文社科类 | 半角方括号 `[1]`，条目内中文用全角标点（作者间用逗号） |

著录格式（GB/T 7714-2005，与通用规范 §7.1 一致）：

```
［1］林来兴. 空间控制技术［M］. 北京：中国宇航出版社，1992：25-42.
［2］辛希孟. 信息技术与信息服务国际研讨会论文集：A集［C］. 北京：中国科学出版社，1999：45-49.
［3］赵耀东. 新时代的工业工程师［M/OL］. 台北：天下文化出版社，1998［1998-09-26］. http://www.ie.nthu.edu.tw/....
［12］谌颖. 空间交会控制理论与方法研究［D］. 哈尔滨：哈尔滨工业大学，1992：8-13.
［13］KANAMORI H. Shaking without quaking［J］. Science, 1998，279（5359）：2063-2064.
［104］CHRISTINE M. Plant Physiology: Plant Biology in the Genome Era［J/OL］. Science，1998，281：331-332［1998-09-23］. http://www.sciencemag.org/....
```

要点：

- 文献类型标识 `[M]` 专著、`[C]` 论文集、`[J]` 期刊、`[D]` 学位论文、`[P]` 专利、`[S]` 标准、`[R]` 报告、`[EB/OL]` 电子资源；带载体时写成 `[M/OL]`、`[J/OL]`
- 外文作者**姓前名后、名用缩写、不加点**（`KANAMORI H`）
- 三位以上作者写前三位加“等”/“et al.”
- 卷期页码齐全：`1998，279（5359）：2063-2064`
- 每条左对齐、悬挂缩进，条目之间不空行

## 14. 结尾四部分（范例明示）

| 部分 | 内容与格式 |
|---|---|
| **结  论** | 章级标题（黑体小2号居中）。内容三块：本文做了什么 → **创造性工作逐条列出（1. 2. 3.）**→ 不足与后续研究 |
| **参考文献** | 见 §13 |
| **攻读博士学位期间取得创新性成果** | 理工类用（一）（二）（三）三项：发表的学术论文 / 申请及已获得的专利 / 参与的科研项目及获奖情况；人文社科类用一、二、三、四、四项：发表的学术论文 / 发表的国际会议论文 / 参与的专著 / 参与的课题项目。专利无则不必列。每条附收录号（SCI/EI、IDS 号、IF）与**对应论文第 X 章** |
| **原创性声明和使用权限** | 两页合一：学位论文原创性声明 + 学位论文使用权限。题目空位、作者签名、导师签名、日期留空**手签**，不要代签、不要打印签名图片 |
| **致  谢** | 导师、实验室师生、基金资助（“本课题承蒙××××基金资助，特此致谢”）。**具体到人和事**，不要模板化 |
| **个人简历** | 出生年月 → 本科（学校/院系/专业/学位）→ 硕士 → 博士，用“××××年××月—××××年××月”；获奖情况（不含科研学术获奖）；工作经历 |

## 15. 与通用规范的关系

本文件管**研究生学位论文专有**的部分（封面、内封、双语题注、层次编号、页眉、成果与声明页）。下面这些照旧走 `formatting-spec.md`：

- 物理量与单位（斜体/正体、GB 3100～3102）
- 数字用法、外文字母正斜体
- 三线表线宽细则、插图编排细则
- 公式转行与注释细则
- 标点与引号（全角、中文引号、书名号）
- 打印与装订（A4、版心 150 mm）

两边都没写的，按通用规范最近条款处理，并在交付说明里注明。
