# 大一年度项目报告排版细则

适用于哈工大基础学部「大一年度项目」的立项报告、中期检查报告、结题报告（本部 + 深圳校区）。

## 0. 与通用规范 `formatting-spec.md` 的关系

学校模板只交代了少数几条（A4、正文小四宋体、图表五号字），大量细节没写。缺的部分**不是随便定**，而是回落到 HIT 通用规范：

> **模板写明的 → 以模板为准；模板没写、写不清、或只给模糊说法的 → 一律按 `formatting-spec.md`（HIT 通用规范）。**

冲突顺序：**模板明示 > HIT 通用规范 > 通行学术惯例**。

常见空缺与回落取值：

| 模板没写清的部分 | 回落条款 | 实际取值 |
|---|---|---|
| 三线表线宽 | §5 插表 | 顶线 / 底线 1.5 磅，栏目线 0.5–0.75 磅，无竖线 |
| 公式编号与排版 | §4 公式、§8.5 | 另起行居中，编号右端对齐；**编号按一级标题序号编排**（如 `（1-1）` 表示第一部分第 1 个公式），与通用规范的“按章编排”同构 |
| 插图图题、图中说明、编排 | §6 插图 | 图题在图下，图序连续，正文先出现“如图 X 所示” |
| 目录 | §8.3 | 章标题黑体小四，其余宋体小四 |
| 物理量符号与单位 | §1、§2 | 符号斜体（含下标），单位正体，量与单位间空一格 |
| 数字用法 | §3 | 阿拉伯数字，年份不缩写 |
| 标点与引号 | §9 | 中文全角标点；双引号用“”，单引号用‘’，禁止英文直引号 `"`；书名用《》 |
| 印刷与装订 | §8.6 | 按通用规范的印刷装订要求执行 |
| 参考文献著录细节 | §7 | 与本文第 6 节示例一致；冲突时以模板示例为准 |

两边都没写的细节：按通用规范最近条款处理，并在交付说明里注明“模板未规定，按 HIT 通用规范处理”，不要静默自创规则。

**模板已经写明的，不要再套通用规范**（否则两份文件打架）：

- **表序、图序**：模板要求“表 1、表 2……”与“图 1、图 2……”连续编号 → 用连续编号，**不用**通用规范的“表 1-1、图 1-1”按章编排
- **标题层级**：模板要求 `一` → `1.` → `（1）` → 用这套，**不用**通用规范的“第 1 章 / 1.1 / 1.1.1”
- **表题、图题字号**：模板明确五号 → 用五号，通用规范对应条款不再叠加

## 1. 页面

| 项 | 值 | 出处 |
|---|---|---|
| 纸型 | A4（210×297mm） | 两校区模板均写明 |
| 页边距 | 上下左右各 **2cm** | 本部明文“页边距各2”；深圳模板实测 2cm |
| 文档网格 | **46 字 × 43 行** | 仅本部明文要求；深圳只要求 A4 |
| 行距 | **固定 16 磅** | 本部明文要求 |
| 正文 | **小四（12pt）宋体**，阿拉伯数字与英文 **Times New Roman** | 两校区一致 |
| 页码 | 页脚居中，正文起页 | 模板用 PAGE 域 |

深圳校区的模板只写了“A4 + 小四宋体”，未写网格与行距。**统一按本部的 46×43、16 磅执行**，视觉上与官方模板一致，也不会被判不合规。

## 2. 封面

封面是评审第一眼看到的东西，字号错了很明显。

| 元素 | 格式 | 说明 |
|---|---|---|
| 编号 | 小四宋体，左上角 | 仅本部中期、结题有 |
| 校名 | **一号（26pt）黑体加粗，居中** | 深圳写“哈尔滨工业大学（深圳）” |
| 报告名 | **一号（26pt）黑体加粗，居中** | “大一年度项目立项报告”等，两行排列 |
| 字段标签 | 四号（14pt）加粗，首行缩进约 2.4cm | “项目名称：”“项目负责人：”等 |
| 制表单位 | 四号加粗，居中 | 本部：“哈尔滨工业大学基础学部”（立项）/ “…制表”（中期、结题） |
| 填表日期 | 四号加粗，居中 | “填表日期：　年　月　日”，留空格待填 |

字段行按模板固定成对排列，别自行增删：

```
项目名称：                                        ← 独占一行
项目负责人：              学    号：
联系电话：                电子邮箱：
专业（类）：               辅 导 员：             ← 本部立项
专业集群：                辅 导 员：              ← 本部中期
院系及专业：                                     ← 本部结题 / 深圳结题
学    院：                                       ← 深圳立项、中期
指导教师：                职    称：
联系电话：                电子邮箱：
学院（部）：                                     ← 本部立项
```

**注意区分**：封面校名/报告名是 **一号（26pt）**；结题报告正文里的论文题名才是 **二号（22pt）**。规范文字里的“题目（二号黑体）”指的是正文题名，不是封面。

## 3. 表格

两类表，规则不同，别混：

| 类型 | 处理方式 |
|---|---|
| **正文里自己做的表**（数据表、进度安排表、经费使用表、方案对比表、测试结果表） | **一律三线表**，规格见下 |
| 学校模板固定的表格（成员表、项目成果表、专家意见栏、批准经费栏） | 保留原网格框线，照着模板交——这几处是学校表格本身，擅自改三线表会被退 |

| 元素 | 格式 |
|---|---|
| 表头 | 五号（10.5pt）宋体，居中 |
| 表体 | 五号宋体，居中；签字列留空手写 |
| 边框 | 正文表用三线表；模板表保留原框线 |
| 行高 | 成员表留足 6 行以上签字空间 |

### 三线表规格

| 项 | 要求 |
|---|---|
| 三条线 | 顶线 **1.5 磅**、栏目线 **0.5–0.75 磅**、底线 **1.5 磅**（模板未规定线宽，取值来自 `formatting-spec.md` §5） |
| 禁止 | 竖线、表内横框线、单元格底纹、合并表头的花式排版 |
| 表题 | 表**上方**，五号宋体居中，写作“表 1　××参数”，题末不加标点 |
| 编号 | 全文连续（表 1、表 2…）；图表分编，别共用序号 |
| 表头 | 每列必须有列名；单位写在列名里（如“时间/月”“金额/元”），不在单元格里重复写单位 |
| 对齐 | 文字列左对齐，数字列按小数点或末位对齐 |
| 长表跨页 | 续页重复表头行，并在右上角标“续表 1” |
| 空白 | 无数据写“—”，不要留空单元格 |

三线表在 Word 里的做法：选中表格 → 边框设为“无” → 只加顶线、底线（1.5 磅）与表头下框线（0.75 磅），再隐藏竖线。

成员表列（按校区替换“所在”列）：

| 姓名 | 性别 | 所在专业（类）/专业集群/院系/学院 | 学号 | 联系电话 | 本人签字 |
|---|---|---|---|---|---|

结题“项目成果”表：序号 | 名称 | 说明。

## 4. 正文

| 层级 | 格式 |
|---|---|
| 一级标题（一、二、三…） | 四号（14pt）加粗，左对齐；模板段前间距不统一（0 或 6pt），统一设 6pt 更整齐 |
| 二级标题（1. 2. 3.） | 小四宋体加粗，空两格起 |
| 三级标题（（1）（2）） | 小四宋体，空两格起 |
| 正文段落 | 小四宋体，首行缩进 2 字符，行距 16 磅 |
| 图题 | 五号宋体居中，**图下方**，写作“图 1　××示意图” |
| 表题 | 五号宋体居中，**表上方**，写作“表 1　××参数” |
| 图表内容 | 五号宋体 |
| 参考文献 | 五号宋体，悬挂缩进 |
| 标点 | 全角标点；引号用“”‘’，不用英文直引号 |

**标题层级只用一种体系**：`一` → `1.` → `（1）`。别混用“1.1”“1.1.1”。

## 5. 结题报告正文的论文式排版

结题报告的第五部分是“论文体”，模板对它有额外要求：

| 元素 | 格式 |
|---|---|
| 题名 | **二号（22pt）黑体，居中，不超 20 字** |
| 学院名称　第一作者，第二作者 | 四号（14pt）楷体_GB2312，居中 |
| 指导教师姓名及职称 | 四号楷体_GB2312，居中 |
| 摘要 | **五号（10.5pt）宋体**，300 字左右；含目的、方法、主要观点、结论 |
| 关键词 | 五号宋体，3–5 个，分号分隔，写作“关键词：词1；词2；词3” |
| 一级标题 | **四号（14pt）黑体，居中，上下各空一行** |
| 正文 | 小四宋体，首行缩进 2 字符 |
| 作者简介 | 首页地脚，五号宋体 |

摘要写法硬要求（模板原文）：简写目的、写明方法、**详写结果与结论**、突出创新性；避免“对……具有重要意义”“具有……价值”这类评价语；避免“本文”“笔者”等第一人称。

楷体缺失时（macOS 无楷体_GB2312）：用系统“楷体 / STKaiti”，再缺就用 Noto Serif SC 顶替，并在交付说明里标注替换情况。

## 6. 引注与参考文献

**正文引注**：顺序编码制，按出现先后 `[1] [2] ……`，**上角标**，与文后条目一一对应。只列已公开发表且在文中加注过的文献。

著录格式（模板原文示例，脚本 `refs_audit.py` 的渲染规则与此一致）：

```
[1] 作者姓名，作者姓名. 参考文献题目[J]. 期刊或杂志等名称，年份，卷(期数)：文章起-止页码.
[2] 刘凡丰. 美国研究型大学本科教育改革透视[J]. 高等教育研究，2003，5(1)：18-19.
    （没有卷的直接写 2003，(1)）
[3] 谭丙煜. 怎样撰写科学论文[M]. 沈阳：辽宁人民出版社，1982.5-6.          （中文图书）
[4] 作者姓名. 参考文献题目[D]. 南京：南京农业大学，2002.                    （学位论文）
[5] 作者姓名. 参考文献题目[N]. 人民日报，2005-06-12（第几版）.             （报纸）
[6] 作者姓名. 电子文献题名[EB/OL]. 出处或可获地址，发表或更新日期.          （电子文献）
[7] 作者姓名. 参考文献题目[A]. 主编. 论文集名[C]. 出版地：出版单位，出版年. 起-止页码.  （论文集）
[8] 外国作者（姓在前全拼大写，名缩写，姓与名之间隔半格，作者间逗号分隔）. 参考文献题目[M].
    译者译. 出版地：出版单位，出版年. 起-止页码.                            （译著）
```

- 中文标点用全角（，：；），条目末尾用英文句点 `.`
- 三位以上作者可写“***，***，***，等”
- 文献条目五号宋体，编号与正文上角标必须一致

## 7. 交付前格式自检

- [ ] 页面 A4、四边 2cm、网格 46×43、行距 16 磅
- [ ] 正文小四宋体，数字与英文 Times New Roman（含表格内数字）
- [ ] 封面：校名与报告名一号黑体加粗居中；字段四号加粗；无空缺
- [ ] 封面字段名与校区匹配（专业（类）/专业集群/学院/院系及专业）
- [ ] 一级标题四号加粗；标题层级只有 `一` → `1.` → `（1）`
- [ ] 结题：题名二号黑体、作者与导师四号楷体、摘要与关键词五号、一级标题四号黑体居中上下空行
- [ ] 正文所有自建表为三线表（无竖线、无内框线），顶线与底线 1.5 磅、栏目线 0.5–0.75 磅
- [ ] 模板固定表格（成员表、成果表、意见栏）保留原框线，未被改成三线表
- [ ] 图题在下、表题在上，编号连续，正文有“如图 X 所示”
- [ ] 全文无英文直引号（搜 `"` 为 0），引号均为“”‘’，标点为全角
- [ ] 参考文献五号，上角标编号与条目顺序一致
- [ ] 页码存在；表格未跨页断裂到只剩一行
