# 模板填充：有原件就别新建

## 为什么必须走这条路

学校下发的原件里，封面横线不是画出来的线段，而是**带下划线的空格 run**（例：21 个半角空格 + 下划线）。自己新建文档、自己敲下划线空格，几乎必然出现：

- 一行 5 个字段的横线右端参差不齐（每个字段标签字数不同）
- 横线长度不够，填进去的字把线顶出去或折行
- 表格合并单元格重建后列宽不对，签字栏跑到第二页
- 页眉页脚、页码起始值丢掉

所以：**只要 `templates/` 里有对应原件，就复制原件填空，不新建封面、不重绘表格。** 只有在原件缺失（如学院另发、课程报告无模板）时才走自建流程。

> 路径说明：仓库里 `templates/` 在根目录；skill 装到 `~/.workbuddy/skills/` 后，由仓库根的 `install.sh` 在 `hit-standard-word-type/` 内建软链 `templates → <仓库>/templates`，所以下文所有 `templates/...` 相对路径两种场景都成立。找不到时先跑 `bash install.sh` 补软链。

## 三步走

### 1. 复制原件到工作目录

```bash
cp "templates/undergrad-thesis/本科毕业论文（设计）开题报告.docx" \
   "<作业目录>/交付-开题报告.docx"
```

`templates/` 下的文件**只读**，任何情况下都不直接改。

### 2. 看槽位

```bash
python3 <hit-standard-word-type>/scripts/fill_template.py inspect 交付-开题报告.docx
```

输出形如：

```
P13#4        下划线空位    专业                 21.0 |
P14#4        下划线空位    学生                 21.0 |
T0r0c1       表格单元格    项目名称                  |
```

- 第一列是槽位号，第二列是类型（下划线空位 / 空白位 / 表格单元格 / 整段）
- 第四列是空位宽度（半角单位，中文算 2），填超了会警告
- `--all` 连正文段落一起列；`--json` 给脚本用

### 3. 写映射表再填

```json
{
  "P8+": "基于深度学习的路面裂缝检测方法研究",
  "P13#4": "计算机科学与技术",
  "P14#4": "张伟",
  "P15#4": "2021112345",
  "P16#2": "李国强",
  "P17#4": "2026 年 3 月"
}
```

```bash
python3 scripts/fill_template.py fill 交付-开题报告.docx 交付-开题报告.docx --map 封面.json
```

用 `fill <原件> <产出>` 一步到位也行，脚本不会写回原件。

## 槽位语法

| 键 | 作用 | 用在 |
|---|---|---|
| `P13#4` | 填第 13 段第 4 个 run（下划线空位），**按原宽度补空格**，横线右端不动 | 封面字段 |
| `P8+` | 在第 8 段末尾追加文字，保留标签 | 「题 目：」这类没下划线的题头 |
| `P24` | 整段替换；值里有 `\n` 就拆成同格式的多段 | 正文占位段「（正文 宋体小4号字…）」 |
| `after:P25@24` | 在第 25 段后插入，段落格式克隆第 24 段 | 标题下面没有占位段时，别克隆标题的黑体格式 |
| `T0r3c3` | 写表格第 3 行第 3 列，保留单元格内字体 | 大创封面、成员表 |

**插入类操作按段号倒序执行**（脚本已处理），所以映射表可以按原文段号写，不必自己换算。

## 两条拦截规则

脚本会拦住最容易犯错的两件事，命中时**不写入**并给出正确键：

| 你写的键 | 情况 | 脚本反应 |
|---|---|---|
| `T0r4c3` | 该格是标签「电子邮箱：」 | 警告「值应填右侧一格 T0r4c4」，不写入 |
| `P8` | 该段是「题 目：」这类带标签的段 | 警告「会删掉标签，改用 P8+」 |

确实要覆盖就加 `!`：`T0r4c3!`、`P8!`。写完检查一遍警告，别放过。

## 纯提示行模板

`大创/项目进展报告-延期用.docx` 这类没有空位、只有五行提示语（「按计划进度安排执行的情况…」）的表，用 `after:P2` 往每行后面插正文段；没有占位段可克隆时，`after:P{行}` 会克隆提示行本身的格式，插入后再按规范改一次字体即可。

## 横线长度的算法

空位宽度 = 原 run 里空格的半角数；填入文字按「中文 2、英文数字 1」折算，差多少补多少空格：

```
原空位 21 个半角 → 「计算机科学与技术」9 字 = 18 → 补 3 个空格，线长不变
```

填不下时脚本会警告「超出空位 X 个半角宽」，此时**改短文字**（如「计算机科学与技术」→「计算机」加专业方向），不要改模板、不要删标签。

## 正文怎么填

- 有占位段（`（正文 宋体小4号字…）`）：直接用 `P24`，多行文本自动拆段，段落格式沿用占位段（宋体小四、首行缩进 2 字符）
- 没有占位段：`after:P25@24`，把正文插在标题后面、格式克隆占位段
- 参考文献表：只填条目文本，**编号与顺序由 `refs_audit.py` 生成**，不要手写 `[1]`
- 分页位置不手动插入分页符：模板本身已有分节，正文溢出自然会翻页

## 文本框封面

`本科毕业论文单独封面参考.docx`（14 个文本框）、`深圳-大一年度项目-中期检查报告.docx`（2 个）这类封面文字在 `w:txbxContent` 里，python-docx 改不到。处理顺序：

1. 优先用本地 Office 编辑能力（`workbuddy-local-office-edit` / editor_sdk）直接改文本框文字，所见即所得
2. 需要脚本批量填时，解包 `word/document.xml`，在 `<w:txbxContent>` 内按原文精确替换文字节点，**不新建文本框**
3. 无论如何不要把文本框拍平成普通段落——一改就错位

## 校验

填完必须做，缺一项都可能白干：

- [ ] 导出 PDF 看首页：封面所有横线右端**在同一竖直位置**，文字不压线、不折行
- [ ] 逐字段核对：题目、姓名、学号、专业、日期、指导教师全部到位，没有 `(无标签)` 遗漏
- [ ] 表格行列数与原件一致（`len(table.rows)` / `len(table.columns)` 对比），签名栏没有被挤到下一页
- [ ] 正文首行缩进、字号与原件占位段一致（不要继承标题的黑体）
- [ ] 页数与原件相差 ≤1 页（封面 1 页固定，正文按内容增长）

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 横线变短/变长 | 直接替换了空位文字，没补空格 | 用 `P{idx}#{j}`，别手改 run |
| 「题 目：」标签被吃掉 | 用 `P8` 整段替换 | 用 `P8+` 追加 |
| 正文变成黑体 | 克隆了标题段落（`after:P25` 不带 `@`） | 用 `after:P25@24` 指向宋体占位段 |
| 段号错位 | 先插入了段落，后面的段号全变 | 脚本已按倒序处理；自己写脚本时也要倒序 |
| 表格列宽变了 | 用 `add_row` / 重建表格 | 只写 `cell.text`，不增删行列 |
| 打开提示「文档已损坏」 | 手改 XML 没保住命名空间 | 用 python-docx 或 editor_sdk 写，别字符串拼 XML |
