# 排版开工前必答的五问

## 硬闸门

**接手排版任务，第一个动作是问，不是改。** 五问答完并得到用户确认前，**只读不写**：可以打开文档看结构、列问题清单，不许保存、不许覆盖、不许“先改两处给他看看”。

三条例外，其余一律先问：

| 情况 | 处理 |
|---|---|
| 用户一句话已说清（“这份开题报告按教务处模板排，只改格式”） | 跳过提问，但**先复述一次**（见下）再动手 |
| 用户说“你定 / 随便 / 你看着办” | 按默认值执行，交付说明里逐条列出假设 |
| 用户催“别问了直接改” | 用默认值 + 一句话说明将要做什么，然后动手 |

反例（都算违规）：上来就调字体字号、边改边问、一次只问一个问题挤牙膏、凭文件名猜规范（把大创申请书当大一年度项目排）。

## 五问（一次问全，附推荐答案）

| # | 问什么 | 为什么要问 | 默认值 |
|---|---|---|---|
| 1 | **这是什么文档？** 课程报告 / 大一年度项目 / 大创 / 本科毕设 / 研究生学位论文或实践成果 | 五套规范互不通用，判错整篇白排 | 不设默认，必须问清 |
| 2 | **哪一支？** 见下方分支表 | 同一活动不同支的封面、章节、字数全不同 | 不设默认，必须问清 |
| 3 | **用哪份版式？** ①`templates/` 里的学校原件 ②老师/学院这次发的模板 ③都没有，按规范自建 | 决定走「原件填空」还是「自建版式」，直接影响封面横线 | 有原件用原件 |
| 4 | **改到什么程度？** ①只改格式，文字与章节不动 ②允许调结构（增删章节、改标题层级、调图表位置）③连内容一起补 | 决定能不能碰正文；越界改内容会毁掉用户已定稿的文字 | 只改格式 |
| 5 | **怎么交付？** 改原文件 / 另存新文件 / 另要 PDF；文件名怎么叫 | 覆盖原件不可逆 | 另存新文件，不覆盖 |

**分支表（第 2 问按第 1 问的结果追问）**

| 第 1 问答案 | 必问的分支 |
|---|---|
| 大一年度项目 | 校区：本部 / 深圳 |
| 大创 | 赛道：创新训练 / 创业训练 / 创业实践；阶段：申请书 / 进展报告 / 验收书 |
| 本科毕设 | 阶段：开题 / 中期 / 结题；门类：理工类 / 人文社科类 |
| 研究生学位论文 | 硕 / 博；学术学位 / 专业学位；学位论文 / 实践成果；门类：理工类 / 人文社科类 |
| 课程报告 | 六类里哪一类（实验/调研/综述/课程设计/读书报告/小论文） |

**附加一问（可并入第 3 问）**：学院这次有没有额外的格式要求（字号、页边距、封面字段、页眉文字、字数）？有就按学院，没有才按仓库规范。

## 复述模板

问完不要直接开干，先用一句话复述，等用户点头：

> 我按 **本科毕设 · 开题报告 · 理工类** 处理：用 `templates/` 里的教务处原件填空，只改格式、不动你写的文字，另存为 `开题报告-排版1107a.docx`。对吗？

复述里必须出现：**规范归属 + 版式来源 + 改动范围 + 交付文件名**。四项缺一项，说明你还没问清。

## 名字与日期

交付文件名遵循用户的版本规则：`原名-排版 MMDD + a/b/c`，例：`开题报告-排版1107a.docx`；同一天再改一版就叫 `…1107b.docx`，**不要覆盖上一版**。

## 问不出来时怎么办

- 用户说不清文档类型 → 让他发作业要求原文或学院通知截图，别猜
- 判定为「规范未收录」（研究生开题/中期/预答辩）→ 如实说还没内置，要素材或模板，不要拿学位论文规范硬套
- 文档里已有明显格式但用户没说改什么 → 把看到的问题列成 3~5 条清单给用户勾选，再动手
